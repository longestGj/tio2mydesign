# DOC-000 Content Architecture V0.3

## 0. Control

Gate 2 status: `SUBMITTED_FOR_USER_GATE_5_REVIEW / NOT_APPROVED`.

## 1. Old → New

```text
Hero → six large category explanations → three Scope cards
→ request-process section → prepare checklist → request CTA → four FAQ

becomes

Hero → Document Finder → Results → assisted Request Documents
→ compact Document Types → Important Notes → three FAQ
→ final Request Documents
```

Finder, Results and Request are promoted because they answer the buyer's immediate questions: where to search, what is public, what action is available and how to request the rest.

## 2. Exact module contract

### Hero

H1 remains `Documents & Compliance Guidance` to preserve the current page identity.

Copy: `Find technical, safety, quality, origin and compliance documents for TiO₂ Malaysia products. Search by product or grade, then view public documents or submit a request when additional documentation is required.`

Actions: `Find Documents` → Finder; `Request Documents` → receiving workflow. Service fact: `Document Language — English`.

### Finder

Fields: Product/Grade and Document Type only. Button: `Find Documents`. Note: `Documents are currently supplied in English.`

### Results

Default: `Find documents by product or grade` / `Select a grade to begin`.

Current no-public-record response after a search: `No public document is listed for this selection. You can request the selected document. Add destination or order / batch information when relevant.`

Verified public results may render only after record approval, with Product/Grade, Document Type, Revision/Version, Date, English, relevant Scope and View/Download.

### Assisted conversion

Heading: `Can't Find the Document You Need?`

Copy: `Tell us the product or grade and document type required. Add destination or order / batch information when relevant.`

CTA: `Request Documents`.

### Document Types

Six concise entries: TDS technical properties; SDS safety/handling/storage/hazards; COA batch-specific analytical results; Origin relevant product/purchase/shipment context; Traceability product/lot/batch/supply-chain records where applicable; Compliance product/use/destination review.

Each may include a lightweight specific Request link with Document Type prefill.

### Important Document Notes

- Documents are currently supplied in English.
- COA and some traceability records may require batch or order information.
- Origin and compliance documentation may depend on destination and purchasing context.
- A request does not guarantee availability or regulatory coverage.

### Buyer Questions

1. Can one document apply to every grade or market? — `No.` Scope may vary.
2. Are documents available in other languages? — Documents are currently supplied in English.
3. What if I cannot find the document I need? — Submit Request Documents with Grade and Type; add context when relevant.

### Final CTA

`Request Documents` with a concise reminder of required fields.
