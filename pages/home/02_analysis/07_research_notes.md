# TiO₂ Malaysia 同行首页研究记录

## 研究范围

- 研究路径：方案 B，20–24 个正式样本。
- 样本类型：全球 TiO₂ 制造商、国际化工分销商、Malaysia/区域工业原材料企业。
- 自有基线：`mytio2.com`，不计入同行模块出现频率。
- 全部样本保存统一桌面完整首页截图；8–10 个深度样本增加移动端完整截图。
- 首页截图保存抓取当日的公开页面状态。异常、重定向、公告或不可访问状态必须如实记录。

## 研究边界

- 仅研究公开网站，不登录、不提交表单、不访问受限文件。
- 不复制同行文案，不因模块高频出现就认定本项目必须采用。
- 同行公开主张不自动视为已经证明的行业事实。
- 模块是否适合 TiO₂ Malaysia，必须同时通过客户相关性、RFQ 支持、IKHLAS 证据能力、Malaysia-origin 差异化、双站边界和视觉标准审查。
- 关键词研究人工审核前，不锁定首页结构、正式文案、最终导航或 URL。

## 截图与来源记录规范

- 桌面截图：统一视口，完整页面 PNG。
- 移动端截图：仅限深度样本，完整页面 PNG。
- 每个网站建立 `source-record.md`，记录页面标题、URL、抓取日期、页面状态、网站类型与异常说明。
- Cookie 弹窗在正常关闭后截图，并在来源记录中注明。

## 实际留档结果

- 正式样本：24 个（11 制造商、6 分销商、6 Malaysia/区域企业、1 自有基线）。
- 桌面完整首页截图：24 份。
- 移动端完整首页截图：10 份。
- 可进行实质内容分析的同行首页：20 个。
- 访问状态样本：Chemours Ti-Pure 与 Univar UK 为 Cloudflare challenge；Brenntag 根站只显示国家/语言选择器。三者保留为抓取当日公开访问状态，不计入实质模块频率。
- 自有基线 `mytio2.com` 只用于双站边界分析，不计入同行频率。

## 编码口径

- `03_homepage_sequence_matrix.csv` 中 `1` 表示首页可观察到该主题，`0` 表示未观察到，`NA` 表示页面内容不可评估。
- 一段内容可同时承担多个主题；矩阵用于横向观察，不是页面质量评分。
- `02_module_inventory.csv` 记录决策意义较高的模块，不穷举 cookie、招聘页脚链接等全部 UI 元素。
- “证据存在”只表示页面上存在某种公开材料或具体信息，不表示研究人员已验证其真实性。

## 频率概览（20 个可评估同行）

| 模块主题 | 观察数 | 解读 |
|---|---:|---|
| Hero / positioning | 20 | 基础模式，不能形成差异化 |
| Products | 19 | 高需求，但产品罗列本身不等于采购决策支持 |
| Applications / markets | 16 | 有助于技术买家自我筛选 |
| Quality / technical | 19 | 高相关，但大量页面停留在主张层 |
| Documents / compliance / reports | 16 | 文件入口常见，深度与可核验性差异很大 |
| Manufacturing / facility | 9 | 实拍和具体设施比抽象工业图更有信任价值 |
| Supply chain / logistics | 11 | 制造商偏过程/产能，分销商偏网络/物流 |
| Sustainability | 14 | 高频但对本项目首要采购问题的优先级较低 |
| News | 11 | 企业透明度辅助项，不宜占据 RFQ 首屏 |
| Direct RFQ as primary homepage action | 0 | 本项目可差异化，但没有同行转化效果证明 |
| Sample CTA | 2 | 更适合作为牌号确认后的次级动作 |
| Gated document request | 0 | 与本项目资料控制策略相符的明显差异化 |

> 上表是基于截图和矩阵的人工主题编码，数字用于方向判断，不是统计学结论或 SEO/转化承诺。

## 移动端观察

- 许多同行在移动端形成超长单列页面；新闻、招聘和公司内容会把采购 CTA 推到很深的位置。
- Tioxide、INEOS 的卡片/手风琴比桌面复杂网格更容易在移动端理解。
- LB Group 在移动端重复 `Request a Sample`，行动明确，但 cookie 弹窗和长产品卡片占据大量空间。
- DKSH 的模块完整但移动端页面极长，说明“信息齐全”与“决策效率”并不等价。
- `mytio2.com` 已在移动端保留三个首屏 CTA；新站若继续使用同一组合，需要通过品牌角色和决策路径避免重复。
