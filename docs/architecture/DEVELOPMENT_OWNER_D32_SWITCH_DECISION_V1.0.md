## 3. 技术与页面交接

当前首页已批准D32方案为WordPress直接管理内容并生成页面，来源为[首页D32交付包V0.2](../../pages/home/06_handoff/HOME-001_D32_GATE6_HANDOFF_PACKAGE_V0.2.md)。本决定不把旧Next.js/API/共享CMS实现作为D32强制基线，也不将首页技术细节扩张为其他页面已批准的实现合同。

业务事实、批准正文、URL、关键词、品牌、共享组件语义、SEO/GEO与站点隔离结果继续继承。对后续页面，Gate6/8须明确D32目标、适用接受条件、实际技术映射、依赖与原授权；涉及改变批准语义的差异交原owner。旧实现路径不能机械替换成D32路径，旧commit/Build/runtime不能冒充新证据。

Gate9以D32实际交回的精确制品与证据执行。Next.js专属检查不自动适用于WordPress；有差异时按有效页面交付合同记录对应验证方法与未验证范围，不伪造兼容通过，也不因更换框架取消验收要求。

D16历史任务不再作为新开发/返修的派发目的地。本次只更新D23文档，不向其他任务发送消息、不停止运行服务、不操作旧生产环境。
