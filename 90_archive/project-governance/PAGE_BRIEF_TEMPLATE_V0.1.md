# TiO2 Malaysia 单页任务卡模板 V0.1

## 使用说明

本模板是每一个具体页面的执行合同。使用时复制为：

```text
docs/page-briefs/{PAGE_ID}_{SHORT_NAME}_BRIEF_V0.1.md
```

填写前必须读取：

1. 根 `AGENTS.md`。
2. `docs/architecture/PAGE_REGISTRY_V0.1.md` 中对应页面记录。
3. `keyword-research/11_page_keyword_master.csv` 中对应完整行。
4. 最新已批准 PRD。
5. 对应页面类型 Playbook。
6. 与本页有关的已验证事实、视觉标准和既有批准成果。

模板中的“记录值”在正式任务卡中不得保留为空。无法确认时填写明确状态，例如 `EVIDENCE_REQUIRED`、`DECISION_REQUIRED`、`NOT_APPLICABLE`，并说明它阻塞哪一个审核关卡。不得用猜测填满字段。

## 17. 完成与发布

页面标记 `APPROVED_COMPLETE` 前，必须关闭全部阻塞级问题，并由总控确认任务卡、视觉稿、实现和验证一致。

页面标记 `PUBLISHED` 前，必须获得用户对部署、生产数据、域名、DNS、索引和对外发布范围的明确授权。开发完成、代码合并或预览可访问都不构成发布授权。
