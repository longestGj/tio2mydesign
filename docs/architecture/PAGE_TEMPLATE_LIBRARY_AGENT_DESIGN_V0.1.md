# 页面模板库 Agent 设计 V0.1

日期：2026-09-12。来源：用户提出专门建立模板库的Agent，并同意先设计职责/入库标准、后盘点TiO2 Malaysia首版。状态：角色设计已落档，未运行注册、未盘点或提取模板。

## 决定与范围

建立独立`page-template-library`角色，管理PAGE/MODULE/COMPONENT资源的发现、去重、建档、核验接收及版本维护。模板库不是W1–W5职责，不是新Gate；本次不改其流程。总控可按单独授权协调任务，但不把模板建库设为网站准备必经步骤。

只做候选登记会缺少后续维护责任；直接让角色包办代码改造又会混淆策划与开发。因此角色负责库与提取合同，代码改造交获授权开发者，新增关键判断由不同身份定向核验。暂不新增Skill，待实际盘点出现稳定、独立的方法需求再提炼。

角色：[agent.md](../../agents/page-template-library/agent.md)。配套：[档案与入库合同](../../agents/page-template-library/references/catalog-contract.md)。

## 第一轮拟执行任务

对象为TiO2 Malaysia首版实际页面、对应实现及原设计/审查，先核对准确版本与可访问范围。交付一份候选清单：页面→模块→组件关系、代表例/必要变体、复用价值、本站绑定、已有验证与缺口、推荐提取顺序。用户称首版开发完成不自动视为所有页面已验收。

本轮设计未读取开发源码或运行站点，不预填模板候选或承诺可提取数量。实际库根目录、源实现版本/预览与写入范围在首次盘点任务中确定；输出位置必须在执行前明确，不能无目标启动全站抓取。

## 接收与限制

角色与合同核对：独立于W/Gate、作者不独立自审、原站PASS不外推通用化、准确来源/权利/依赖、目录/版本/查找入口、明确不做事项。设计文件不等于运行配置或已纳入可复用母版；当前15Agent/9Skill发行保持原状。

同步agents目录索引、项目索引与目录说明。无页面事实、URL、品牌、批准状态变化；若需撤销角色设计，移回历史并撤导航，不回退网站业务成果。
