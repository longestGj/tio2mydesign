## 3. Page Intent Card — proposed for Gate 1 confirmation

| Field | Proposed value |
|---|---|
| Audience | Masterbatch formulators and producers, plastics technical buyers, application engineers, quality teams and procurement teams evaluating a TiO2 pigment candidate |

## 4. Buyer strategy

| Field | Value |
|---|---|
| Primary role | Technical decision-maker or formulator |
| Secondary roles | Procurement, quality and supplier-qualification stakeholders |
| Application | White masterbatch and related declared masterbatch systems |
| Buyer stage | `Technical Evaluation / Supplier Search` |
| Known questions | How to define the system; how to compare candidates fairly; what each measurement means; what remains unverified; which records to request; when to progress or hold |
| Main concerns | False comparability, extrapolating process evidence into final performance, unclear document scope, unsupported Grade claims and premature cost conclusions |
| Required decision | Whether the evidence supports the next defined qualification step in the buyer's declared system |

| Success signal | Buyer reaches a qualified next action with the required inputs understood; not merely a long article read |

## 5. Page responsibility

**One-sentence role:** Help a Masterbatch buyer define a two-stage TiO2 evaluation, interpret evidence within its scope, review neutral candidate Grades and prepare the next qualification action.

### 5.1 Must answer

| ID | Buyer question | Decision supported | Planned module | Evidence basis |
|---|---|---|---|---|
| Q01 | What exactly is being evaluated—the pigment, the concentrate or the final article? | Define objects and stages | `evaluation-system` | S01 study plus bounded synthesis |
| Q02 | When is a comparison fair enough to interpret? | Comparable / not comparable / verification needed | `comparison-basis` | S02 ISO public scope plus buyer-defined endpoint |
| Q03 | What can flow, FPV, microscopy and final-specimen tests each tell me? | Interpret complementary evidence | `evidence-interpretation` | S01 and S02 within stated scope |
| Q04 | Can favorable processing evidence qualify final performance? | Prevent stage overreach | `evaluation-boundary` | S01 limited example and explicit inference boundary |
| Q05 | What should I expect from a TDS, SDS, CoA and application report? | Request the correct record for the question | `documents` | S03/S04 examples plus Buyer Clean correction |
| Q06 | What qualification step comes next? | Progress or hold with stated evidence | `qualification-workflow` | Bounded synthesis of S01/S02; not an ISO SOP |
| Q07 | Which TiO2 Malaysia Grades can enter a neutral review? | Open relevant Grade paths without ranking | `grades-to-review` | Product V0.3 matrix and user-confirmed M-2377 authority |
| Q08 | When is a cost comparison meaningful? | Avoid premature savings claims | `economics` | Conditional analytical frame |
| Q09 | What information should I submit? | Create an actionable enquiry | `qualification-inquiry` | Required system/comparison inputs from page |
