# 独立视觉审查：完整检查，不重复生产 V0.2

母版版本：0.1.0（提取候选，尚未安装/发布验证）。运行前读取[实例绑定合同](../../../contracts/instance-bindings.md)；本站事实、授权与进度不随方法复制。

用于明确授权的新Gate 5独立审查，即Gate 4那一次最终独立审查。不是Gate 3范围减免，也不替代Gate 9实际实现验收；不因本参考自动改变阶段权限。

## 方法

先验证交付完整与准确身份，再直接审已有正式三端及长页可读证据，随后独立运行并操作适用路径，最后集中交回Finding。全文、所有模块和适用状态必须覆盖；“按风险保存截图”不等于只抽查内容或只测一个控件。

机器复算尺寸/bytes/SHA与引用闭合，不人工逐图抄录。PNG提供物理像素，DPR由真实捕获配置/运行记录支持；状态和颜色陈述需要实际操作或样式/图像证据，工具PASS不能代替。使用调用方提供的有效工具/原始结果并核对其输入身份与范围，未有统一validator不能虚报已通过。

| 工作 | 正确做法 | 禁止的重复 |
|---|---|---|
| 三端视觉 | 打开执行方正式图，完整读取；实际浏览器核对 | 默认另存三端或整套执行图 |
| 长页 | 原图缩放、现有分段或滚动查看，覆盖所有连接 | 每次审查重建所有分段图 |
| 交互 | 独立实际操作，记录步骤/结果/环境与视口 | 只读作者JSON当自己实测；或每次操作必拍PNG |
| Findings | 记录全部实质问题，局部必要证据 | 无问题时生成大量证明性图或逐项PASS表 |

## 首审覆盖与复审入口

调用方传入 `review_scope=INITIAL | TARGETED`，核验身份始终为 `INDEPENDENT_REVIEW`。INITIAL使用本节完整覆盖；TARGETED先读有效原审查、Finding和实际变化，直接使用修订分类，继承明确未变的已审范围，不机械重跑首审。缺少有效原覆盖或变化边界时说明不能得出完整结论，交Agent处理。

在既有运行记录中组织“要求/状态 → 实例范围 → 视口 → 实测或继承依据 → 缺口”，同类可合并成行，不新增逐控件PASS长表。

| 对象 | 必须检查 | 可避免的重复 |
|---|---|---|
| 正文与视觉 | 三端全部模块、真实内容、关系及连接；源和现有图对应 | 用现有正式图缩放、现有分段或浏览器滚动，不默认生成分段 |
| 断点差异 | 每种实际布局、导航、覆盖层和焦点路径的变化分别运行 | 无差异的宽度不机械重复同一完整行为序列 |
| 同类本地行为 | 每种行为/状态转换由Reviewer独立实测；每个实例的目标、参数、数据关系和组装核对 | 满足下述等价条件时复用同一审查内的代表运行结果 |
| 特殊状态 | 长内容、错误、不同背景、独立脚本、特殊表格/表单分支分别检查 | 不把所有按钮和所有视口做笛卡尔积 |

行为等价必须核实：同一实现及关键依赖、相同状态逻辑/处理器、无改变行为的断点分支、实例参数差异已经核对。不同视觉外观仍逐端检查；同一桌面菜单结果不能覆盖移动菜单的焦点锁定和返回。无法证明等价就分别运行，不能只因外观类似而抽样。实际运行实例和由等价依据覆盖的实例分别记录，后者不得标成逐个实测。

上述复用只减少同一审查中的重复操作，不继承执行者自检作为独立行为结论，不取消合同明确指定的逐实例或逐视口操作，也不自动用于Gate 3或Gate 9。适用状态整体必须覆盖；未满足条件的必需项未测不得PASS。

## 机器输入与写入边界

执行方提供可追溯输入、资产清单及机器结果；Reviewer核对实际文件和运行依据，批量复算路径/bytes/SHA/物理尺寸，关联逻辑视口、DPR、状态及源身份。已有脚本或原生命令可提供同等检查；记录实际命令/工具和范围，不以统一validator尚未实现为由要求另造平台。

清单缺失属于输入缺口，复算不一致属于待修正问题，必要工具运行失败属于执行失败；三者如实交回Agent。机器结果不证明视觉质量，也不能凭PNG尺寸反推实际DPR。颜色陈述须对照对应状态的实际样式/图像。

冻结源与执行方 `evidence_index` 只读；Reviewer的观察和必要证据在获准的独立报告/运行记录中引用原索引。由执行者或有权总控接收后按各自权限维护组合引用，Reviewer不得直接回写冻结索引。每轮新增报告版本，保留原报告。

## 新增截图的允许触发

每张新持久截图在既有报告/运行记录里标注trigger、对象/视口/状态、为何旧证据不足。允许触发仅为RENDER_MISMATCH、EVIDENCE_GAP_OR_UNREADABLE、SOURCE_UNCERTAIN、VISUAL_FINDING、CHANGED_PRESENTATION、EXPLICIT_CONTRACT。不得仅写“独立审查需要”。默认新增重复截图0张；确需全页证明全局问题时记录影响，不设硬数量上限。

浏览器为了实际查看发生渲染是正常检查，不等于必须导出保存另一套截图。证据不足则明确补查，不能以节约为由判PASS。

## 修订分类

- 源/依赖/渲染条件影响页面：正确新冻结身份，受影响视口/状态和相邻回归；布局变化检查三端。
- 仅台账字段：可信未变原件及捕获来源、机器全量复算、修正字段与索引闭合；不重采全部图片。
- 仅陈述错误：与对应实际观察/样式/图像证据比对；证据不足时补该项实测。
- 同一源/依赖/条件与证明对象完全未变：引用有效证据，不生成重复PNG。

实际捕获DPR、状态或来源不能核实，不属于可直接修标签的记录错误。记录修正仍更新其版本及组合引用，旧独立报告不可覆盖；未验证范围不得写成通过。

## 自检与独立审查边界

SELF_CHECK由制作方完成完整自检；INDEPENDENT_REVIEW由不同作者身份执行上述方法。两种模式都不授予Gate批准。本参考不强制执行者少交合同要求的正式图，也不授权Reviewer改页面、修改作者台账、发真实请求或做生产验收。
