## 当前职责

Gate 4更名“页面设计与验证”，吸收Gate 3跨页一致性与结构验证。Gate 3保留历史阶段语义，新页面不单独执行。Gate 2批准内容 → Gate 4同一工作集制作、自检和冻结 → Gate 5不同作者独立审查 → 总控按常设授权关闭一次 → 获授权的Gate 6。Gate 5当前独立审查与历史Gate 5制作编号分开解释。

4A内部确认页面家族、参照批准身份、共享组件、同类模块、必要差异、内容关系、真实状态和视觉方向。成熟模板直接继承；复杂表格、表单或新家族按风险做局部结构验证。不默认完整三端正式线框、单独冻结或独立结构审查。4B完成同一源的1440/768/390整页、适用状态、可读性和操作验证，正式捕获后冻结最终组合。

Gate 5审查必须覆盖跨页一致性、内容/操作关系、视觉和证据身份；不可只审外观。完整内容、44×44px操作目标、必要键盘/焦点、适用状态及不同作者独立性保持。共同方法继承有效未变证据，变化按影响补验；不复制竞争正文或为方法切换重复导出。
