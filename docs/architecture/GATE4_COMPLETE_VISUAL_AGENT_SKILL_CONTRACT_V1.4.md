## 1. 单一工作集

执行Agent在页面开始时创建一个`workset_id`，各项Skill共享以下入口：

| 字段 | 含义 |
|---|---|
| `page_id` | 获授权页面身份 |
| `workset_id` | 本轮完整视觉工作集身份 |
| `authority_manifest` | 当前页面唯一Manifest |
| `input_index` | Brief、Gate 2、可继承的历史Gate 3、品牌、共享owner及决定的精确引用与身份 |
| `design_source` | 同一可编辑设计源及耐久依赖 |
| `evidence_index` | 资产、状态、操作观察、Finding及证据类别的唯一索引 |
| `allowed_write_scope` | 页面目录、报告路径及允许更新对象 |
| `authorization_scope` | 本页获准工作、停止点和明确未授权事项 |

Skill不得各自复制全文或创建竞争的输入清单、设计源、Manifest或证据索引。身份未变的输入由后续Skill引用并记录已核对；发生变化时更新共同入口并说明影响。

## 2. 方法追加关系

0. `responsive-wireframe-design`按风险补充结构验证，复用同一工作集，不要求独立线框成果。
1. `brand-applied-visual-design`读取共同工作集，形成视觉规则、代表性高风险样例和4A建议；输出追加到设计源与证据索引。
2. Agent实际读取、查看并判断4A。通过时记录`VISUAL_DIRECTION_CHECKED`；需要外部决定时只冻结受影响项。
3. `full-page-visual-composition`接收已通过4A检查的方向，以及相关已批准品牌、文案、结构和共享组件合同；在同一设计源中完成全部实例、三端整页和适用状态。
4. `layout-interaction-verification`可在4A作范围明确的诊断核验，在4B以SELF_CHECK补齐执行方完整预检和正式捕获核对；冻结后由不同实际作者作独立审查。它只写证据与Finding，不修改候选。
5. Agent修订后更新源、受影响资产、冻结身份和证据索引；独立审查者对最终冻结组合及后续返修执行审查/复审。

同一资产和同一输入不因方法切换重复导出或重复报告。已有证据只有在身份与影响范围未变且证明对象相同时才可继承。

## 3. 两个检查点

### 4A `VISUAL_DIRECTION_CHECKED`

最小记录：页面家族/参照批准身份/共享组件/必要差异及owner、内容关系和风险验证、视觉目标、规则映射、代表风险、样例身份、未决项、Agent判断和能否进入整页制作。它是内部检查，不是用户批准或Gate关闭。

### 4B `COMPLETE_VISUAL_FROZEN`

最小记录：设计源及依赖身份、三端完整页面、适用状态、可读分段、实际操作证据、静态/运行/源码/模拟分类、开放项和正式证据索引。冻结后进入唯一最终独立审查环节；返修产生新冻结身份并沿用Finding ID复审。

## 4. 交回格式

每项Skill只返回：

- 实际保存的绝对路径；
- 对共同工作集新增或改变的项目；
- 主要结果与Finding；
- 未完成或不能验证的事项。

执行Agent负责形成简明Gate 4→6接收入口：当前Manifest、冻结组合、最终审查、批准范围、相对上游变化和开放项。不得重抄全部合同。

## 5. 证据和权限

三端完整图是基础证据；长页可用缩放、已有分段或滚动记录保证可读，状态按实际适用性覆盖，不强制每轮另存所有分段。静态图只证明所示外观；真实本地行为、源码观察和模拟结果分别标记。Gate 4不声称开发实现或生产接收已通过。

共同工作集、4A检查或Skill完成都不新增页面权限。只有当前用户决定或已存在的连续授权才能启动、恢复、扩展或关闭具体页面。

Gate 3/4/6常规关闭采用常设授权；Gate 4的4B独立审查通过、必修关闭且身份一致后，由总控登记APPROVED / CLOSED及授权、审查、关闭证据。启动/恢复/扩展仍按实际执行授权。

## 6. V1.2自检效率增补

2026-09-07用户明确“可以，同意修改Gate4的内容。”批准本次收口。各项Skill与Agent共用同一实际覆盖记录；制作中的有效检查可继承，核验补齐缺口，Agent判断就绪，不因方法切换增加全量自检。详细执行按[Gate 4自检方法](../../skills/layout-interaction-verification/references/gate4-self-check.md)。

完整预检通过→锁定源/条件→正式导出→捕获核对与机器身份检查→完整冻结→一次独立审查。源/条件未变时捕获核对不重跑内容、交互和全部测量；异常按影响补验。预检图不冒充正式图。诊断证据按缺口、Finding、采集异常或明确要求保存；历史资产不删除。

SELF_CHECK只在授权执行工作集写入；独立Reviewer只读冻结索引，交回独立报告引用，不能回写。必需覆盖、三端正式图、适用状态、有效冻结及独立审查保持，页面授权和正式Gate编号不因本次改变。
