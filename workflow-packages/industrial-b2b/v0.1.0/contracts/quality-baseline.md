# 通用质量基线

- 响应式基础证据：1440、768、390逻辑宽度的完整真实页面至Footer；Tablet独立布局，Mobile按批准关系重排。780物理像素只能表示390 logical @2x，不能算Tablet。
- 控件实际命中区至少44×44 CSS px；结合键盘可达、可见焦点、对比度、标签、错误、媒体替代文本和合同要求检查。不把CSS属性存在当作视觉结果通过。
- Gate3只解决结构、阅读与操作缺陷；不探索视觉风格、生成媒体或打磨动画。合格基础样式无需去色。
- Gate4三方法共用源/索引与一次完整自检；预检通过后锁源/条件、正式捕获、核对捕获与身份。CAPTURE_CHECK不重复有效完整自检。
- Gate5完整检查三端及适用行为，默认新增重复截图0张；新截图须对应明确触发。完整检查不等于复制证据，不能用节省截图跳过覆盖。
- Gate6无变化/缺口/反证时继承上游，只审跨合同接口和新增映射；新增语义须一次独立复核。总控不成为第二次完整Reviewer。
- Gate9核对实际实现/环境/数据及接受条件，不能继承策划简化规则作为生产免检。静态图、源码、本地模拟与实际运行分别记录。
- 检查发现实质问题后继续覆盖其余适用范围，集中返修。必需未测不得PASS；后置依赖须有来源、owner、接受条件及阻断阶段。
- 行业profile不降低本基线；项目增补须明确批准来源，不能把配置开关当作授权。修改基础阈值须同步Node预检字段及相关证据合同，不能保留touchTargets44却改称其他阈值通过。
