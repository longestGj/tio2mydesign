## 规则案例自检

以下是对条款的桌面推演，不是实际页面运行或独立Agent测试。

| 场景 | 按新条款应采取的行动 | 自检判断 |
|---|---|---|
| 普通市场页沿用有匹配证据的共享包，无CSS/行为覆盖 | 核对原始报告及依赖，实际检查三端连接、菜单/Cookie入口退出；引用完整焦点循环等共享证据，不重复三张Cookie图 | 有明确路径；不能把引用写为本页运行 |
| 组件hash相同，但页面全局CSS覆盖了菜单定位 | 继承条件不成立，复验受影响组件/视口；影响不明则完整复验组件 | 不能仅凭相同hash免检 |
| 390技术表重排后单位或脚注脱离对象 | Gate 3阻塞缺陷，修复对应关系并复验三端 | 不能因减少证据而省掉结构检查 |
| 表单有长错误、选择和提交反馈 | 本页真实状态完整检查，按风险增加必要证据，没有图片数量上限 | 复杂页面不套普通内容页资产数量 |
| 审查建议阴影更柔和，当前无合同/理解/操作问题 | 记录给Gate 4，不为此阻断Gate 3或新建候选 | 视觉偏好不变成必修Finding |
| 链接对比不足或焦点不可见 | 实际可访问性问题，修复；不能列成纯视觉建议 | 保留质量底线 |
| Gate 4调整未锁定的字号/间距 | 保留结构约束，复验受影响布局；不自动重开Gate 3 | 共享owner与历史显式锁定仍有效 |
| Gate 4完整视觉或Gate 9调用核验Skill | 按完整阶段合同检查，不启用Gate 3共享减量规则 | 不把局部控制扩展为生产免检 |
