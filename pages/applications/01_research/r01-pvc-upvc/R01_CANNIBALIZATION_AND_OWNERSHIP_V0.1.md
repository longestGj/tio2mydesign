## Cannibalization result

The existing keyword master currently nests titanium dioxide for pvc inside APP-02. Fresh evidence shows a coherent PVC-specific SERP containing producer application pages, trade-association technical guidance and journal research rather than only generic Plastics pages. That is sufficient to recommend a second-layer article, but not a new primary Application owner.

Internal-link relationship:

- APP-PLAS parent → R01 for PVC/uPVC depth.
- R01 → APP-PLAS parent for the general comparison method and neutral Grade review.
- R01 → APP-MB only when the buyer's primary system is PVC masterbatch/concentrate production.
- R01 → R02 only after R02 itself is approved and available.
