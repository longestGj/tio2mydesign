# Gate 3跨页一致性与Gate 4布局职责决定 V1.0

日期：2026-09-20。决定ID：G3-CONSISTENCY-20260920。状态：USER_APPROVED / ACTIVE。

## 1. 批准来源与范围

用户提出列数应由Gate 4确定、Gate 3应保持页面统一；随后提供Home、Markets、Products和Non-China采购指南四页供比较，并对跨页复用、必要差异和阶段分工建议回复“同意你的建议。”本文件记录该具体决定，适用于后续获授权的Gate 3制作、审查和Gate 4接收。

本增补与当前工作流、阶段标准、Agent/Skill基线共同使用。涉及跨页一致性及布局决定权时，本决定优先于旧规则中“Gate 3锁定列数/响应式重排、Gate 4不得调整”的通用要求。原始批准文件保留，不回写历史。

## 2. Gate 3职责

Gate 3负责将本页已批准内容组织进全站一致的页面与组件体系。明确本页的页面类型、信息层级、共享组件、同类模块及行动路径，并与相关页面进行横向对照。相同功能遵循共同规则，页面差异须来自内容与任务需要。具体列数、尺寸、间距、视觉样式及响应式布局由Gate 4在共享设计体系内确定。

- 先找已有模式，再组织本页：核对相关页面及共享Hero、卡片、FAQ、行动区等适用模式，明确复用对象、批准身份、适用范围和owner。沿用既有视觉基准承接要求，不默认以首页为全部页面模板。
- 同类模块共用组件，允许有依据的变体：记录内容和功能差异，区分共享规则、受控变体和本页专属内容。新视觉变体由Gate 4设计；涉及已有共享合同变化时交相应owner处理。
- 统一操作含义与行动层级：进入详情、展开答案、选择条件和提交请求应有稳定含义；同一组件跨页不得任意改变行为。操作外观由Gate 4实现，已批准目标、字段和结果语义保持。
- 交付必须横向对照：在既有报告或交接中记录“参考页面/组件—本页使用—必要差异及依据—Gate 4待解决事项”，不强制新增独立文件或截图配额。

统一按全站共享、页面家族、专属内容分层。文章可采用内容页结构，不强套一级导航页；摘要市场入口和带国家子级的市场入口可有不同信息密度，但应明确共同组件关系。已有批准的开放白底等选择继续有效，不因追求统一恢复被否决的设计。

## 3. Gate 3→4交接及布局边界

Gate 3保留完整批准内容、模块任务与顺序、信息关联、共享组件绑定、行动目标和行为语义。线框中的列数、宽度、间距、视觉位置和响应式排列均为结构验证时的当前方案，不由Gate 3新增为视觉锁定项。

Gate 4根据内容密度、阅读和操作需要确定列数及响应式布局，并复验受影响的完整内容、关联关系、可读性和交互。只改变这些布局选择且不改变上述语义约束，不自动退回或重开Gate 3。若改变批准内容顺序、对象关系、行为语义或共享合同，按实际归属定向处理。

既有页面专属批准或共享owner合同中的明确几何约束不被本决定静默撤销；Gate 4需要改变时按原合同变更机制处理。此项继承不允许Gate 3继续自行把新列数方案设为不可变约束。

Gate 4接收时须能回答：本页属于哪个页面家族、引用哪些有效共享组件、与哪些页面保持一致、哪些差异有内容依据、哪些设计需在共享层解决。Gate 5在原有最终独立视觉审查中核对跨页一致性，不增加审查轮次。

## 4. 制作、审查与停止条件

本次不取消现行完整内容三端线框、必要操作、冻结、自检和独立审查要求；它们证明内容关系和可操作性，不构成最终版式锁定。是否另行简化三端线框制作，尚未在本决定中作出。

Gate 3审查增加跨页复用和差异依据核对。遗漏适用共享合同、同类组件行为矛盾或无依据的独立分叉属于本阶段问题；纯视觉精细度由Gate 4处理。发现共享设计缺口时明确owner与Gate 4待办，不要求Gate 3提前完成完整视觉。

## 5. 实例证据与实施边界

四页桌面观察显示：Markets/Products同类后续入口分别使用描边按钮和文字箭头，FAQ分别为展开问答与折叠卡片；首页与文章的市场卡片、页尾行动区也存在不同表达。这些用于说明为什么需要受控复用，不把每项差异自动判为违规，也不证明差异由Gate 3造成。截图中部分页脚Logo未显示属于待核验观察，不是已确认实现缺陷。未测试移动端及交互，不构成Gate 9验收。

本决定不修改具体页面、共享视觉值、运行注册、模板库或D32代码，不自动启动页面、开发、部署或发布。历史Manifest、在途批准组合和阶段状态不批量迁移。方法源版本保持原身份，通过当前基线必读本项目增补；不声称已完成新版方法的真实页面试跑。

主要风险是把统一理解为全页同模板，或把布局自由理解为允许改变语义；上述分层与边界用于避免这两种误用。回退应有新的有效决定，只回退本增补及当前入口指针，保留历史和并行任务改动。
