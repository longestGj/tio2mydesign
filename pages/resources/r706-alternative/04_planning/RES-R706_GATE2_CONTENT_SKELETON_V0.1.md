This Skeleton defines a buyer journey for an R-706-specific qualification task. It does not approve the candidate URL, mapping, indexing, publication, final copy, Gate 2 or any later Gate.

## Buyer task and route

The reader already uses or evaluates Ti-Pure R-706 and needs to organize an independent qualification exercise without being given a cross-supplier product answer.

Primary route:

`Establish the R-706 reference` → `define the current use and acceptance criteria` → `select relevant tests` → `explore IKHLAS Grades independently` → `request documents` → `request a sample when a Grade and test context are ready`

## Module order

### 1. Hero — Qualify Another TiO2 Supply When Ti-Pure R-706 Is Your Reference

- State the exact task: turn the buyer's current R-706 use into a controlled evaluation brief.
- Explain that the page does not select an IKHLAS Grade or predict test results.
- Primary CTA: `Explore Titanium Dioxide Grades` → `/products/`.
- Secondary anchor: `Build Your Evaluation Brief` → `#evaluation-brief`.

### 2. Establish the R-706 Reference

- Attribute R-706 identity, process and listed coating applications to the current Ti-Pure product page.
- Use the February 2020 Product Information sheet to distinguish the stated minimum from values labelled typical.
- Tell the buyer to record the exact source and version used as the control reference.
- Show source links and review dates.

### 3. Build an R-706-Specific Evaluation Brief

- Gather the current coating system and route, substrate, end use, exposure, finish, control formulation, acceptance criteria, test methods and required evidence.
- Make clear that partial information can start the work; the buyer can add missing detail before a document or sample request.
- Keep this checklist specific to the R-706 task rather than reproducing the broad brand-level method owned by `RES-CHEMOURS`.

### 4. Plan Tests Around the R-706 Evaluation Dimensions

- Group possible dimensions by appearance/optics, formulation/process, durability/mechanical performance and handling.
- Attribute the R-706-specific prompts to the Ti-Pure sources.
- Require the buyer to choose only relevant dimensions and define methods, controls and thresholds.
- Do not imply that any IKHLAS Grade has passed or will pass them.

### 5. Understand the Scope of the TS-6706 Announcement

- Attribute the February 2025 statement only to Chemours and the named TS-6706/R-706 pair.
- Use its test categories as possible planning prompts, without transferring its conclusion to another supplier or Grade.
- Direct the buyer back to their own R-706 control formulation and acceptance criteria.

### 6. Continue with a Buyer-Selected Grade

Present three sequential routes:

1. **Explore Products:** compare the Product Hub's application and process information; no R-706 context, preselection or recommended candidate is carried into the Hub.
2. **Request Documents:** after selecting one IKHLAS Grade, request one or more document types. Other Grades may be noted only as supplementary context; submit separate requests if document types differ by Grade.
3. **Request a Sample:** only after selecting a Grade and defining the intended application and test objective. Submission starts human review; any sample arrangement is confirmed separately.

End with a concise trademark/source-independence note and `Last reviewed` date.

## Explicit exclusions

- No named IKHLAS candidate, shortlist, recommendation, ranking or R-706-to-IKHLAS relationship.
- No promise about test performance, compatibility, production outcome, sample availability or document release.
- No M-996/M-2196 differentiation.
- No broad Chemours portfolio guide, general supplier-comparison checklist or competitor-site navigation copy.
- No body RFQ module; the shared global RFQ action remains outside this page-specific route and receives no R-706 or Grade prefill.
- No candidate-URL, canonical, sitemap, indexing or publication approval.
