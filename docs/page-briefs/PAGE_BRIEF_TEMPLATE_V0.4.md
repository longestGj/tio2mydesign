# TiO2 Malaysia 单页任务卡模板 V0.4

> 当前流程：[Gate工作流V3.1](../architecture/GATE_WORKFLOW_V3.1.md)。本版于2026-09-07按用户批准同步Gate 3结构边界、Gate 4合并、Gate 6总审与交付、Gate 8技术承接及Gate 9验收；旧模板和已批准Brief保留。旧模板中已被根规则替代的证据/视口要求一并对齐，不新增事实决定。

## 使用说明

本模板是每一个具体页面的执行合同。使用时复制为：

```text
docs/page-briefs/{PAGE_ID}_{SHORT_NAME}_BRIEF_V0.1.md
```

本项目只负责视觉稿、SEO、GEO、页面内容架构、开发交付规格，以及开发完成后的只读质量验收。本项目不编写或修改任何开发代码；本任务卡不得授权执行 WordPress、Next.js、CMS、代码、测试、部署或发布工作。

填写前必须读取：

1. 根 `AGENTS.md`。
2. 从当前项目索引取得登记册及本页记录，并读取当前Gate工作流。
3. `research/keyword/11_page_keyword_master.csv` 中对应完整行。
4. 最新已批准 PRD。
5. 对应页面类型 Playbook。
6. 与本页有关的已验证事实、视觉标准和既有批准成果。

模板中的“记录值”在正式任务卡中不得保留为空。无法确认时填写明确状态，例如 `EVIDENCE_REQUIRED`、`DECISION_REQUIRED`、`NOT_APPLICABLE`，并说明它阻塞哪一个审核关卡。不得用猜测填满字段。
