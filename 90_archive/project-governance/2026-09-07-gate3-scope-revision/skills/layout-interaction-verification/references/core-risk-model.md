# Gate 3核心不变量与页面专属风险模型

核验开始时先建立两层范围。层级用于保证覆盖和控制证据规模，不是质量打分。

## 固定核心不变量

| 核心 | 必须回答 |
|---|---|
| 冻结身份 | 源、正式图、批准输入和共享来源是否绑定同一冻结组合？ |
| 内容与关系 | 三端是否完整显示B的可见内容、顺序、对象关系和动作；是否出现输入没有的内容？ |
| 响应几何 | 1440/768/390是否无裁切、碰撞、横向越界和异常空白；可见控件是否宽高均至少44px？ |
| 共享组装 | 当前导航、固定CTA、Logo、Footer、法律/Cookie是否消费当前owner且无业务页面血缘？ |
| 覆盖层操作 | 适用菜单/对话框是否实际验证焦点进入、循环、退出、背景隔离和恢复？ |
| 动作边界 | href、上下文和选择语义是否符合C；本地记录、模拟和生产接收是否准确区分？ |
| 完整视觉覆盖 | 是否实际查看三端全页至Footer及全部正式关键状态，而非只看缩略图或脚本结果？ |

## 页面专属风险

从批准内容和合同选择实际存在的类别：

- 技术表或比较：对象、字段、数值、单位、脚注、限定和窄屏对应。
- 连续列表或目录：名称、摘要、入口、顺序、页内锚点和无JS路径。
- 表单或选择：字段、帮助、必填、数量规则、长错误、提交中、失败/成功及接收边界。
- FAQ或展开：入口可发现、完整答案、键盘状态、展开后自然流和Footer。
- 来源/竞争品牌：命题与来源相邻、外链目标、日期、独立性及无视觉等价/推荐暗示。
- 媒体/无图：来源和事实边界、裁切、替代文本方向、失败回退及无占位残留。
- 特殊响应转换：桌面表到记录、并列到单列、跨断点覆盖层关闭或其他对象关系风险。

无真实功能时记录`NOT_APPLICABLE`和依据，不生成虚构状态。每个选中风险给出预期、实际证据、结论和未测项。

## 证据类型

- `ACTUAL_RUNTIME`：在当前冻结源实际操作或测量。
- `STATIC_VISUAL`：打开当前正式或诊断图所得的可见判断。
- `SOURCE_INSPECTION`：源结构、监听器或路径检查，只能支持源码范围结论。
- `LOCAL_SIMULATION`：本地拦截、状态注入或模拟结果，不证明生产接收。

报告按类型写结论。断言总数可记录用于复现，但不得跨页比较、作为通过阈值或替代完整覆盖说明。
