## 3. Gate 4：完整视觉设计与验证

### 3.1 单一责任与共同工作集

一个Gate 4执行Agent端到端负责视觉方向、完整页面应用、核验、返修、冻结和提交。三个能力Skill维护各自方法，不取得页面授权或阶段批准权：

1. `brand-applied-visual-design`：形成视觉规则并用真实高风险样例验证。
2. `full-page-visual-composition`：把已通过4A检查的方向应用到全部页面实例、三端整页及适用状态。
3. `layout-interaction-verification`：核验内容可见性、响应式几何、状态外观和可实际操作的本地行为。

三者使用同一工作集ID、同一设计源、同一输入清单和同一证据索引。后续方法读取前一方法已经核验且身份未变的共同输入，不重复整理全文、重复导出相同资产或另建竞争报告。每项方法只追加自身产物、观察、Finding与未验证范围；执行Agent负责综合。

### 3.2 4A内部检查点

`VISUAL_DIRECTION_CHECKED`是Gate 4内部检查点。它确认视觉重点、品牌用途、信息密度、组件外观、媒体规则和关键响应式风险足以继续整页制作。

4A不是独立Gate，不产生`APPROVED / CLOSED`，也不要求一次单独的用户方向批准。既有方向、家族规则和共享合同足以裁决时，Agent完成检查即可连续进入完整页面制作。出现重大新品牌方向、共享owner变化、内容/结构冲突或超出当前授权的选择时，只提交受影响决定；其余工作可继续。

`full-page-visual-composition`的方向输入必须写为“已通过4A检查的视觉方向，以及相关已批准品牌、文案、结构和共享组件合同”，不得继续要求一个独立Gate 4批准作为启动前提。

### 3.3 4B唯一正式关闭点

`COMPLETE_VISUAL_FROZEN`表示三端完整页面、适用状态、源与依赖已形成可审冻结组合；它仍不是阶段批准。

冻结后只设置一个Gate 4最终独立审查环节。该环节可以产生Finding、返修和多次定向复审；“一个环节”不表示只能检查一遍。最终审查对象包括：

- 批准内容和结构是否完整、准确呈现；
- 视觉是否符合品牌、共享owner和本页任务；
- 1440、768、390完整页面及长页连接是否成立；
- Mobile Menu与页面适用状态是否覆盖；
- 静态外观、实际本地操作、源码观察和模拟证据是否正确区分；
- 版本、依赖、冻结身份、开放项与历史关系是否可追溯。

Finding关闭并经用户批准后，记录`Gate 4 APPROVED / CLOSED`。4A没有单独关闭状态；4B是唯一正式关闭点。

### 3.4 一个权威入口

“一套成果”指一个权威入口和一个冻结组合，不要求一个物理文件。当前Manifest指向：

- 可编辑设计源及其耐久依赖；
- 共享组件、字体和媒体的精确owner引用；
- 1440、768、390三张完整页面基础证据；
- 长页所需可读分段与适用菜单、表单、Cookie等状态证据；
- 对应实际操作证据及其`ACTUAL_RUNTIME`、`STATIC_VISUAL`、`SOURCE_INSPECTION`或`LOCAL_SIMULATION`类别；
- 自检、最终独立审查、Finding/复审和批准记录。

截图证明外观，不自动证明交互行为；策划阶段本地运行或模拟不代替Gate 9对开发实现的验证。Gate 4→6接收文件保持简短，只提供权威入口、适用范围、相对上游的变化、开放项和冻结身份，不复制全部合同。

## 4. Gate 6：总审与Gate 4的边界

Gate 4最终独立审查判断完整视觉是否符合批准内容、结构、品牌、响应式和状态要求。Gate 6判断Gate 1–4全部策划成果是否一致、开发交付是否明确、Gate 9是否具备可执行验收依据。

Gate 6必须引用有效Gate 4审查证据，并按变化、缺口和合同冲突进行复核；没有新证据、身份变化或冲突时，不重做整套视觉验收。若Gate 6发现实际视觉缺陷或冻结组合失配，定向退回Gate 4并按新身份复审。Gate 6自身新增的开发映射与验收合同仍需独立核对。

Gate 6继续负责唯一交付包；正文保持唯一编辑源，交付入口用引用和差异说明组织。Gate 6批准不自动授权Gate 8、开发、派发或发布。

## 5. Gate 8、Gate 9与Gate 10

Gate 8在独立开发项目中完成技术承接、WordPress/API/Next.js映射、实现、测试和回执。D23不进入D16执行这些工作。

Gate 9锁定Gate 6批准包、开发版本和可访问结果，独立核验内容、三端视觉、状态、实际交互、SEO/GEO/Schema、数据来源、共享消费与`site_scope=tio2-my`隔离。Gate 4的策划模拟不能代替开发运行证据；开发自检也不代替Gate 9。

Gate 10及生产部署、域名、DNS、索引和对外发布继续需要用户单独明确授权。

## 7. 当前状态与授权定义

Gate 4可使用以下状态：

`NOT_STARTED / NOT_AUTHORIZED`

→ `USER_AUTHORIZED / IN_PROGRESS`

→ `VISUAL_DIRECTION_CHECKED`（4A内部检查点）

→ `COMPLETE_VISUAL_FROZEN / DRAFT_FOR_PROJECT_CONTROL_REVIEW`

→ `PROJECT_CONTROL_REVIEW_PASS_PENDING_USER_APPROVAL`

→ `APPROVED / CLOSED`

返修与复审保留稳定Finding ID并绑定新冻结身份，不另造阶段。Manifest分别记录生命周期、4A检查、冻结、最终审查、用户批准、下一阶段授权和外部实施状态，不能用其中一项替代另一项。
