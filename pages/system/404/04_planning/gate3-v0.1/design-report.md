# SYS-404 Gate 3 responsive structure report V0.1

## Input and scope

The exact input identities are in `input-binding.json`. This source consumes Shared Global Chrome Gate 3 Consumer V0.2. Because its API requires a mapped navigation key, generation uses `HOME-001` only to create the owner markup and then removes the two generated `aria-current` attributes. This realizes the approved SYS-404 zero-current contract without copying another page or changing shared sources.

## Structure decisions

The short recovery message occupies one centered reading block between complete shared Chrome and Footer. The two approved Primary actions remain a separate group before the three Supporting actions. At 390 all five actions become full-width single-column controls; wording, order, targets and hierarchy remain exact. At 768 the groups wrap independently. No page-local image, form, search, FAQ, recommendation, redirect or error variant is added.

Current type, spacing and basic colors are readable planning parameters. Gate 4 owns complete visual refinement while preserving the approved structure, order and action hierarchy.

## Runtime boundary

The source intercepts links only as local navigation-intent evidence. It does not send requests. HTTP 404 delivery, valid-route non-interception, destination availability, sitemap/robots enforcement, analytics sanitization and site-scope isolation remain DEP01–DEP07 for Gate 6/8/9.
