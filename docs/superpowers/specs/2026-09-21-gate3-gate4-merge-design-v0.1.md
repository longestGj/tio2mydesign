## 2. 问题和目标

当前Gate 3已把列数、尺寸、间距和响应式布局决定权交给Gate 4，但仍要求三端完整线框、预检、正式导出、冻结、独立审查和阶段关闭。Gate 4随后确定最终布局并再次完成三端验证及冻结。两者目的有所不同，但完整制作和阶段管理存在重叠。

目标是由一个执行负责人在同一工作集中持续完成跨页一致性、结构、视觉和验证，以最终成果证明要求。减少默认中间交付，不减少实际内容、操作和独立审查覆盖。没有真实试跑前不宣称节省具体比例或已证明质量提升。

## 3. 方案选择及编号建议

不采用“同一Agent连续跑两关、保留两套正式交付”的方案，其交接成本降低但重复资产和关闭仍在。不采用直接删除结构检查的方案，其跨页一致性容易被视觉制作掩盖。

推荐保留Gate 4编号并更名为“页面设计与验证”，吸收原Gate 3职责；Gate 3作为历史独立阶段保留。Gate 5继续承担最终独立审查角色，生命周期沿现行4→5合同归入同一设计组合，由总控关闭一次。Gate 6不重做该审查。

执行关系：Gate 2批准内容 → 合并Gate 4制作、自检、冻结 → Gate 5独立审查 → 总控关闭设计组合 → 获授权的Gate 6。

保留编号是兼容选择，不要求全库文件重命名或改变后续Gate 6/8/9/10。当前工作流中“Gate 5仅为历史编号”与现行独立审查角色的说明须同步统一，明确历史Gate 5制作与当前Gate 5审查的区别。

## 4. 一个负责人、两个内部检查点

执行负责人承接Gate 2全文、内容/行为合同、批准记录、适用品牌及共享owner合同。原Gate 3完整冻结组合不再是新页面的启动必要条件。

### 4A：一致性、结构与设计方向检查

在共同设计记录中明确：

- 页面家族、参照页面的批准身份、适用共享组件和同类模块。
- 本页使用方式、必要差异及内容/功能依据、共享缺口及owner。
- 完整文案与模块关系、行动层级、真实状态和高风险区域。
- 品牌、视觉方向及待验证布局；已有有效模式直接继承。

这是内部检查，不单独冻结、独立审查或关闭。复杂表格、表单、新家族或高风险状态可先作局部原型验证；已有成熟模板可直接展开整页。不默认要求一套正式三端线框。发现内容或共享合同冲突时定向交原owner，其余获授权工作继续。

### 4B：整页制作、验证与冻结

在同一设计源完成1440、768、390逻辑视口的完整页面及适用状态。最终列数、尺寸、间距、响应式和视觉由同一负责人在共享体系内决定。完整检查批准文案、关系、可读性、操作、44×44px目标、焦点、对比度和共享组装。

制作过程的检查在身份、范围和证明对象仍有效时直接继承；修改后补验受影响范围。完整预检后锁定源与条件，正式捕获、核对身份、冻结最终组合。自检和独立审查仍分开。返修保留旧版和稳定Finding ID，不原地覆盖已交审源。

## 6. 正式交付与独立审查

正式交付为一个准确的组合入口：批准输入、跨页映射、可编辑设计源及耐久依赖、三端完整成果、适用状态和操作证据、自检、冻结身份和开放项。文件可以分存，但不维护竞争正文和第二个当前Manifest。

独立审查由不同实际作者负责，同时覆盖：

1. 本页是否消费正确的共享合同和页面家族，差异是否有依据。
2. 完整内容、对象/字段关系、行动和状态是否符合批准合同。
3. 三端布局、视觉、阅读和操作是否成立。
4. 源、证据、依赖、版本和未测范围是否对应。

不得把“统一”理解为所有页面同模板，也不得因为合并而允许删文案或改变动作。未关闭必修不能PASS；真实生产路由或接收依赖按后续Gate验证，不冒充本地验证完成。总控核对权限、独立性、准确组合和必修关闭后关闭一次；Gate 6启动及开发/发布仍需各自授权。

## 7. 历史和在途兼容

| 页面情况 | 处理 |
|---|---|
| 尚未开始设计 | 新规则激活且设计范围获授权后，直接进入合并制作 |
| Gate 3已关闭、Gate 4未开始 | 继承有效结构和跨页映射，不重做；按原Gate 4授权完成剩余设计 |
| 仅获原Gate 3授权 | 仍以原授权停止点为限；不能凭合并自动开展完整视觉 |
| Gate 3制作中 | 总控记录源、已完成覆盖和原授权；获完整设计授权后转入同一工作集，否则保留原范围 |
| Gate 4制作或Gate 5审查中 | 复用现有组合，仅核对是否缺一致性或结构覆盖，不重启全部制作/审查 |
| 已关闭页面 | 保留历史编号、批准源、hash和证据；有新变更才按受影响范围应用新规则 |
| 明确暂停页面 | 继续暂停；治理合并不构成恢复授权 |

不批量修改页面Manifest。总控在实际接收或继续该页时登记等价映射；历史Gate 3独立通过仍为真实历史，不补造新的合并阶段批准。
