## Responsive decisions

- **1440:** 1,200px content shell. DE-02 uses three equal application records; DE-05 uses a prose/checklist pair. The remaining modules use a controlled reading width or full-width conversion panel.
- **768:** shared narrow Header is used. Application records and the destination checklist become a deliberate single-column sequence; this is an independent Tablet layout, not a scaled Desktop grid.
- **390:** complete single-column flow. Hero actions become full-width; long headings, owner links, source labels and the five destination inputs wrap naturally. Footer utilities and procurement action remain directly reachable.
- The page has no page-specific image. This avoids implying a route, German facility, warehouse, inventory or local service and needs no invented no-image state.
