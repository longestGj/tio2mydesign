## 4. OG / Social / Schema Image

No image output is mandatory. If no concrete Gate 8 Asset key is selected, omit image properties. If an asset is selected, social/Schema output must:

- reference the named derived/approved Asset key;
- match the visible ABOUT-001 page;
- use neutral semantic text;
- record the final asset hash;
- avoid hidden factual inference.

This is an output-selection rule, not a statement that the user's body-visual approval is insufficient.
