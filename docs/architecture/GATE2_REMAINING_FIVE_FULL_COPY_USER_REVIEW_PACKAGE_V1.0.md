## 3. Concrete page decisions

### RES-R706

- H1: `Qualify Another TiO2 Supply When Ti-Pure R-706 Is Your Reference`
- Primary action: `Explore Titanium Dioxide Grades` → `/products/`.
- Buyer task: turn an existing R-706 use into a controlled evaluation brief, choose a Grade independently, and qualify it in the buyer's own formulation and process.
- Critical boundary: the page does not claim an IKHLAS equivalent, replacement or performance match. The TS-6706 announcement is kept within Chemours' own two-grade evidence and test program.
- Closed review issues: TS-6706 was corrected to the sole announced test subject; R-706 page versus Product Information evidence was separated; bulk-flow testing was separated from paint-system tests.
- Project Control: [review](../../pages/resources/r706-alternative/05_review/RES-R706_GATE2_FULL_COPY_PROJECT_CONTROL_REVIEW_V0.1.md).

### RES-TRADE-EU

- H1: `EU Titanium Dioxide Anti-Dumping Duty: Current Measure and 2026 Review`
- Primary action: `Review EU Procurement Options` → `/markets/european-union/`.
- Buyer task: distinguish Regulation (EU) 2025/4's current fixed duties from the 2026 absorption reinvestigation, then prepare shipment-specific inputs.
- Critical boundary: exact producing legal entity, TARIC additional code and specified valid commercial invoice must align for an individual or cooperating-company rate; otherwise the all-other path applies, subject to Customs checks.
- Current dated fact: the regulation remained marked in force on 7 September 2026; Notice C/2026/4533 had reopened an absorption reinvestigation but did not create a new current rate.
- Project Control: [review](../../pages/resources/eu-trade/05_review/RES-TRADE-EU_GATE2_FULL_COPY_PROJECT_CONTROL_REVIEW_V0.1.md).
