## 1. Requirement N01 — Evaluation Hierarchy

### Review concern

The V0.1 Direct Answer could imply that every listed performance dimension always requires both documentary evidence and application testing.

### Implemented wording

> Opacity, hiding power, undertone, weatherability, dispersion and formulation suitability should be evaluated using current grade-specific evidence and, where relevant, application-specific testing under the buyer’s intended conditions.

### Result

The hierarchy is now explicit:

`route context → grade-specific evidence → where relevant, buyer-condition validation`

Status: `RESOLVED / CLOSED_IN_V0.2`.

## 2. Requirement N02 — Tronox Source Scope

### Review concern

The prior wording could be read as proving that each production route separately covers coatings, plastics and décor paper. The Tronox source does not support that stronger inference.

### Implemented evidence roles

- LB Group BLR-886 and LR-108 provide the direct evidence that chloride- and sulfate-process rutile grades can both appear in the plastics application family.
- Tronox provides broader portfolio-existence context only: it states that it uses both processes to make products used by manufacturers of coatings, plastics and décor paper.
- The page explicitly states that Tronox is not used to prove that each route separately covers all three application families.
- The examples are specified as compact cited evidence examples, not competitor product cards.

Status: `RESOLVED / CLOSED_IN_V0.2`.

## 3. Requirement N03 — Gate 1 PQ-05 Closure

### Review concern

> Route labels also do not establish price, production economics, availability or general versatility. Those depend on the specific product, application, supplier and transaction and are not compared on this page.

This closes PQ-05 without introducing current price/cost claims and without adding a fifth FAQ.
