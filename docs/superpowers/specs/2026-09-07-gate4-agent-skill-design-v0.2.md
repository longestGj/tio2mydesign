## 2. 本轮关键细化

| 事项 | 本轮设计 |
|---|---|
| 结构和视觉边界 | 列数、模块/控件所属位置与优先级继承Gate 3；字体、间距导致的自然换行与高度变化可在视觉范围内处理 |
| 已含视觉的线框 | 正确继承已有批准处理，只补真正缺口，不机械将其灰度化或重新换风格 |
| 样例选择 | 每种新视觉处理有真实样例；复用规则可映射，长内容、背景和状态改变风险才增加样例 |
| 检查范围 | 完整检查全部已交样例，报告明确全页未覆盖；局部核验不冒充Gate 5整页验证 |
| 规则精度 | 数值、共享token或可判定响应规则与样例对应；不把“适当留白”交给Gate 5重新猜测 |
| 功能色和媒体 | 在实际背景/状态核对，图形不增加事实含义；布局核验不代替这些视觉判断 |
| 方法交回 | 精确输入、源、图、规则、身份和证据一一对应；Agent实际读回与查看后接收 |
| Gate 5接手 | 按规则完成全页与全部实例；新视觉决定定向交Gate 4，结构交Gate 3，内容/行为交owner |

## 3. 用户当前可审阅的设计选择

1. 一个Gate 4执行Agent对方向和结果负责，默认推荐一个有理由的方向，有实质取舍才制作备选。
2. 一个新方法负责品牌应用与真实样例制作，复用现有布局交互核验；不强制拆出独立视觉Review岗位。
3. 使用三端代表区域与适用状态证明方向；按规则覆盖选样例，不规定固定数量，不重复制作Gate 5完整页面。
4. 规则与真实样例一致、全部样例实际检查、关键问题已处理且组合可定位后送审；独立审查和用户决定仍按既有项目流程。

本轮新增的候选源和上述细则未记为用户逐字批准。Gate 2不设专属Skill的用户决定继续保持，探索文件不删除、不重新推广。

## 4. 风险、同步与回退

风险是样例不足导致无法指导整页，或样例过多造成重复工作。本版用“不同处理有证据、复用位置可追溯、遇新风险补样例”平衡；真实效果仍需后续行为验证。

另一个风险是把本地候选文件存在误当已批准方法，因此角色、Skill、目录与索引都显式标注候选状态。没有自动加载、安装、注册、页面改稿、开发或发布操作。

同步范围：新增两份候选源及本记录，更新Agent目录、Skill目录和项目索引的Gate 4导航。Gate 1–3源文件、页面Manifest、共享标准和初版设计保持。后续实质修订保留候选快照，再升级相应源和设计记录；未采用时保留历史并移出有效入口，不删除证据。
