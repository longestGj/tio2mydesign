## 2. 试验设计与独立性

使用一个固定英文合成页面，包含三条虚构技术记录、六节完整长文和本地请求表单。不是三个独立真实页面。输入锁定内容、顺序、单位、脚注、错误/确认消息与中性菜单合同；壳为 Example Evaluation Desk，不是 TiO2 共享组件。完整逻辑宽度1440、768、390，均按1x输出；没有用780替代390。

依据 skill-creator 的独立前向验证方法，三个子代理只取得分配的原始输入、方法及候选，分别承担设计、A核验、B核验。设计者不读受控缺陷；首次B核验不读预期答案、构建脚本或控制者测量。之后由B核验者独立检查设计者产物；A核验者依据旧Finding复验C、D。后两种复用不描述为全新盲测。

总控构建A与含六类注入缺陷的B，在交给核验者前保存预期清单；A不是已知无缺陷对照。A任务名称含`clean_trial`，暴露了比较组意图，因此不声称A严格盲测，不估计无偏误报率。本轮没有无Skill条件，不声称Skill造成统计上的能力提升。

本地浏览器实际渲染和操作；设计者使用本机Chrome，独立核验使用Chromium 151。表单全部为虚构输入与本地确认，运行记录未捕获外部请求。没有访问开发项目、发送消息、下载安装依赖或调用付费设计服务。

历史证据统一在[归档入口](../../../90_archive/skills/2026-09-07/gate3-method-validation/README.md)。以下链接均指向归档副本，避免唯一证据只存在临时工作区。

## 4. 核验方法的发现与修订复验

六类预先注入缺陷均在[首次B报告](../../../90_archive/skills/2026-09-07/gate3-method-validation/review-b/report.md)中被发现。下表是本样本类别对应，不是通用准确率。

| 预先注入的行为 | 首次Finding |
|---|---|
| 手机数值、单位及条件在58px框内裁切，但页面无横向溢出 | LIV-B-01 |
| 手机三条记录脚注隐藏 | LIV-B-02 |
| 隐私说明及链接被固定高度裁切 | LIV-B-03 |
| 数量输入框高48px但宽仅28px | LIV-B-04 |
| 菜单从模态改成非模态，背景可达且焦点外泄 | LIV-B-05 |
| 无效提交聚焦Submit而非首个无效字段 | LIV-B-06 |

核验者还发现未列入六项注入的真实合同偏差：`min=0.01`拒绝合法正数0.001，记为LIV-B-07；[A报告](../../../90_archive/skills/2026-09-07/gate3-method-validation/review-a/report.md)也记录同因A-01，不能重复计算为两个不同问题。

A-02记录原生模态菜单末项Tab短暂进入浏览器界面焦点，页面背景仍不可达；它违反本练习“始终留在菜单”的严格合同，与B的背景泄漏不同，不推导为原生dialog普遍有缺陷。

总控保留A/B并创建C修订。[C复验](../../../90_archive/skills/2026-09-07/gate3-method-validation/review-c/report.md)确认多数接受条件满足，但留下菜单链接关闭后焦点落BODY，以及390长Beta选中名称裁切。长选中值曾在A被列为建议；C明确更正分类依据，原报告未被改写：前缀可识别只证明没有选错记录，不能证明合同要求的完整名称可读。

进一步创建D，调整菜单关闭事件中的焦点返回，并使390选择框容纳完整两行名称。[D有限定向复验](../../../90_archive/skills/2026-09-07/gate3-method-validation/review-d/report.md)确认：

- 390/768全部五个菜单链接关闭后，焦点返回Menu且目标滚动正确；Close、Escape、正反Tab及背景焦点隔离保持。
- 390长Beta在错误/成功状态完整换行可读，0拒绝、0.001成功，值、隐私说明与链接保持。
- 7张D供图由实际源逐像素复现；有限相邻回归未发现新缺陷。原披露入口视觉标记的建议没有宣称已处理。

以上是原Finding在本轮接受条件下的结果，不编辑旧报告，不关闭项目Gate。D为受控核验样例，不作为正式网站组件或可直接部署模板。

## 7. 尚未证明的内容与下一步边界

本轮证明两项方法能在一个合成样本上完成实际产物交接、发现所设缺陷并支持修订复验。尚未覆盖真实TiO2页面与共享组件组装、完整Agent输入获取/授权/返修流程、其他浏览器及实体移动设备、辅助技术、极端用户输入或外部数据接收。

旧截图混入、缺少交互源、文件写入失败等分支没有分别做专门故障注入；设计导出中的一次真实失败不能等同于全部失败处理已覆盖。完整跨视口交互矩阵也未跑满，具体范围以各报告为准。

下一步宜将已批准角色细则整理为项目Agent入口，明确读取当前Gate2成果、调用两项方法和交回独立审查的连接，再选择有明确Gate3授权的代表页验证完整流程。该工作与实际页面授权另行记录，本次没有提前启动。
