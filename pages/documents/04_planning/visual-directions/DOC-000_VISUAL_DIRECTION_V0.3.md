# DOC-000 Visual Direction V0.3

## Direction

`Industrial Document Finder Tool` within the existing TiO2 Malaysia system.

- Hero is shorter and task-led.
- Deep Navy Finder is the strongest functional surface.
- Results immediately follow Finder and use factual record rows.
- Assisted Request Documents is visible directly after Results.
- Document Types and FAQ are visually quieter supporting modules.
- Important Notes compress evidence/scope into a light-gray information band.

## Preserved system

Navy/Teal, white/light gray, typography, grid, cards, buttons, Production SVG, 84px Desktop Header, 64px Mobile Header, fixed Documents current state and Deep Navy Footer are unchanged. Request a Quote remains global Chrome only.

## Record/action hierarchy

- Find Documents: primary Finder control.
- View/Download: only verified public record actions.
- Request Documents: primary assisted conversion.
- specific Request links: secondary text actions.

## Mobile

One-column fields, records, types and CTAs. No carousel, two-column small cards or clipped metadata. Touch targets ≥44px.

## Imagery

No fake certificates/PDF previews, factory photos, molecules, stock imagery or decorative document mockups.
