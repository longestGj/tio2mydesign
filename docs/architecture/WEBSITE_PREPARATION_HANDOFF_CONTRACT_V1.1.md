# 网站级准备与逐页准入交接合同 V1.1

2026-09-11。USER_APPROVED / ACTIVE_PROJECT_SOURCE。决定ID：SITE-PREP-20260911。
用户在[复盘与设计](WEBSITE_PREPARATION_RETROSPECTIVE_AND_WORKFLOW_DESIGN_V1.0.md)交回后要求“执行下一步”，授权细化总控职责及最小交接模板；不授权启动新网站或页面。该设计作为本合同依据保留其原历史状态。

## 1. 对象与责任

网站级准备使用work_type=SITE_PREPARATION、site_id和原控制记录，不伪造Page ID、页面Manifest或Gate编号。沿用STATUS/PREPARE/START/RESUME/ACCEPT_RESULT：START须有具体网站与准备范围授权，无授权仅准备。新站无项目入口时由获授权准备任务逐步建立准确资料入口，不把已有完整Context/PRD作为准备工作的循环前提；已有项目按根规则读取和复用。

总控组织W1企业与产品事实基础、W2市场/客户/竞争分析、W3商业战略与网站定位、W4网站架构与采购旅程、W5生产准备与批次安排；五包不是五个审批Gate。专业执行者负责成果和自检，独立审查者负责新增关键判断与依据，总控检查包间一致性并登记用户决定，不重复同范围专业审查。总控实质创作的专业结果须由不同身份审查，不能自签PASS。

W1先整理企业实际供给、来源/允许用途/局限；W2以客户需求、竞争与替代选择为战略提供依据，不以竞品宣称证明其实际能力；W3匹配企业能力与市场机会，提出取舍供用户决定，不擅改企业战略。搜索需求在W2支持判断，W4再落实页面归属；W2–4可按明确缺口有界迭代；W4明确页面/关键词/导航/转化/恢复路径及owner；W5仅准备首批输入和依赖，不提前制作全站文案、视觉、代码或完成运行验收。

## 2. 最小输入与交回

使用[模板](WEBSITE_PREPARATION_HANDOFF_TEMPLATE_V1.1.md)或现有等价章节，不强制新增独立JSON或五份报告。

必须可定位：site_id与准备范围/授权；企业品牌/产品服务/目标市场语言的来源；已批准与待决定范围；复用输入身份及用途；W1–5实际缺口和责任；专业成果/审查链；首批页面候选与依赖；停止点和下一步权限。没有页面身份时使用明确候选，不生成假Page ID。

网站基线由指定总控维护为唯一来源入口，不复制原事实正文、不替代PRD或页面Manifest。配置分别保存业务事实与环境引用，域名、scope、目录、技术栈不在通用模板写死；禁止记录凭据。客户资料跨站复用须验证适用性与使用授权，不能继承另一站的阶段批准。

关键未知项标明待确认、owner、影响和最小解决动作；允许NA但需依据。未知与不适用不同。缺搜索量不等于无需求或低商业价值。

## 3. 审查、就绪和停止

独立检查重要方向、事实/关系、架构分工和首批接口；已有有效专业审查按身份/范围/时效继承。总控接收原成果及证据而非聊天PASS。用户决定业务方向、企业事实、网站范围及重大变化；可集中提交关联决定，不为每包新增审批。

交回结论采用现有编排状态并写readiness_scope和unresolved_items：就绪只表示指定首批具备准入输入。条件为目标/主体/读者/行动明确、职责无严重未决冲突、核心命题可追溯、共享依赖有owner、Gate 0输入可取得。未授权的首批只能PREPARE，不以COMPLETE_WITHIN_SCOPE授予页面启动。

未知实时外部事实按权威证据定向核验；企业缺证交具体用户命题；未实现共享功能登记后续责任，不自动阻断Gate 1–4。反证不得借继承忽略；只暂停受影响决定，不重启无关研究。必需判断完成后停止，不因文件数量或可选润色继续扩展。

## 4. Gate 0与Gate 1

Gate 0接收获批页面身份/范围、URL资格、关键词职责、Brief、网站基线相关来源、关键缺口、原始授权和停止点。网站准备不替代页面准入；原始准入标准保持，不为新增本合同重做历史页面。

Gate 1接收准入结果、已知买家答案、有效研究及本页缺口，按现行三路径选择方法；不能默认全量重做网站研究，也不能因网站级PASS免审。文章仍按原文章工作线从Gate 1承接，Gate 2内容适配保持。

## 5. 增量与能力建设

已有网站新增页面只补受影响来源和准入；同企业第二站可继承有效事实但重核站点分工和公开用途；新行业调整产品/服务模型，不强套型号/TDS、市场子页或固定转化表单。具体设备、法律、接收验收要求按合同与风险确定，准备阶段不复制本项目最重矩阵。

本版按用户后续决定建立[企业与产品事实基础Agent V0.1](../../agents/enterprise-product-facts/agent.md)，负责W1六部分及先读资料、整理事实、集中补问、确认和交回。暂不新增专属Skill；W2–W5具体角色和内容继续逐包讨论，不自动创建。旧V1.0“本次不新增专业Agent”是当时范围，不能覆盖本次明确决定。
