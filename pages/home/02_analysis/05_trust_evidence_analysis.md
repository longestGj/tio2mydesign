# 信任证据分析

## 采购风险与证据映射

| 买家担忧 | 同行常见做法 | 可信度判断 | TiO₂ Malaysia 可用证据输入 |
|---|---|---|---|
| 原产地是否真实 | 工厂/矿山图片、法律实体、站点地址、origin statement | 只有可追溯到本企业材料时才成立 | COO 样本/说明、制造地点、运营主体、出口协调地点、来源记录 |
| 合规是否真实 | 资源中心、法规服务、证书、法规新闻 | 新闻/图标不能替代具体文件与有效性 | REACH-related 文件、SDS/TDS、资质编号、机构、有效期、查询渠道 |
| 产品是否适用 | 应用卡片、产品/牌号页、技术中心、样品 | 应用标签需有技术资料支持 | 牌号清单、应用建议、关键指标、TDS、技术人员确认流程 |
| 供应是否稳定 | 垂直一体化、产能项目、仓库、地图、物流服务 | 必须有当前、可核实的能力资料 | 工厂、仓库、包装、装柜/港口、出口流程、可披露的供应机制 |
| 质量是否稳定 | 实验室、QC、管理体系、COA | 实拍图和流程比泛化“high quality”更有价值 | QC 流程、设备/人员、批次 COA、检验节点、可披露的认证 |
| 公司是否真实 | 法律实体、注册地址、管理层、历史、联系方式 | 基础事实必须跨页面一致 | IKHLAS 公司注册信息、地址、电话、域名邮箱、公开阵地一致性 |

## 观察到的高价值证据模式

1. **过程证据**：Tronox 的 mine-to-pigment、KMML 的容量项目、DKSH 的服务/覆盖路径，能回答“能力如何形成”。
2. **实物证据**：Tioxide、INEOS、TTPL、Excel Chemical、APCC 使用工厂、实验室、人员或仓库画面；真实性和相关性高于抽象化工图库。
3. **具体数字**：IMCD、DKSH、Safic-Alcan 用国家、中心、客户、年限等数字；数字有效但只可在拥有日期、口径和来源时采用。
4. **可核实文件入口**：Tioxide、INEOS、DKSH 将资料或资源中心做成明确入口；本项目应转换为受控申请，而不是直接公开下载。
5. **法律主体与地址**：PRECHEZA、区域供应商在页脚提供法律信息；这对跨境采购的尽调比笼统“trusted partner”更有效。

## 证据强度分级

- A 级：可核验原始文件、编号/机构/有效期、企业自有实拍、批次文件、真实地址和主体登记。
- B 级：有负责人、日期、过程说明或可追溯来源的内部材料。
- C 级：企业公开主张，但没有在当前资料包中提供底层证据。
- D 级：通用图库、抽象图标、空泛优势、未经授权的客户/伙伴 Logo。

首页应优先呈现 A/B 级证据摘要，并将完整材料路由到信任型副页或申请流程。C 级只能标记待核，D 级不应承担关键信任任务。

## 候选信任型副页方向

以下是研究得出的内容承载方向，不是最终 URL 或导航：

- Malaysia origin 与 traceability；
- quality control 与 batch documentation；
- documents / compliance request center；
- manufacturing capability；
- warehouse、packaging 与 export coordination；
- company / legal entity / contact consistency。

## 必须避免

- 把马来西亚旗帜、地标或旅游景观当作原产地证明；
- 将“Malaysia-based supplier”写成“Malaysia manufacturer”，除非制造关系和用词经材料核实；
- 使用未经授权或已失效的认证、客户、协会、合作伙伴 Logo；
- 以库存照片代替工厂、质检、仓库和装运证据；
- 把可申请文件写成公开可下载文件；
- 使用无法说明口径的产能、客户数、出口国家数或交期承诺。

## 待企业资料包补全的证据字段

每项材料建议登记：材料名称、拥有者、来源日期、适用主体/工厂/牌号、可公开范围、有效期、查询方式、需遮盖信息、页面用途、审核人和批准日期。
