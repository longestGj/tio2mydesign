## 检查范围与停止

保留完整批准内容、关系、三端全页、触控区域、基本可读性、焦点可见性及实际操作检查。先从任务输入卡读“结构问题—预期—位置/视口/状态”；每个新增状态图或返修都对应一个具体风险/合同要求，不能为了样式探索增加资产。完整范围无阻塞问题后交回结果；实际Gate关闭由总控按有效常设授权执行；仅在本站授权覆盖时免逐页审核。

| 发现 | 处理 |
|---|---|
| 正文/关系丢失、裁切、CTA遮挡、必要状态无法使用、键盘障碍 | Gate 3缺陷，修复并复验 |
| 输入身份、品牌、事实、共享合同冲突 | 交对应owner；关键冲突未解决不得写PASS，继续不依赖部分 |
| 缺乏关键验证或继承证据不适用 | 未覆盖范围，不可用“没有发现问题”代替验证 |
| 无合同冲突且不影响理解/操作的颜色偏好、阴影、卡片外观、细微留白建议 | 记录位置及原因，交Gate 4；不阻塞Gate 3、不生成返修图 |
| 真实CMS、生产路由、接收、设备等未来实现项 | 记录合同依赖，交Gate 8/9；不以模拟冒充实现 |

建议与缺陷按影响判断，不按它是否属于CSS判断。对比度不足、不可见焦点或违反批准品牌色仍是实际问题。不要把审美偏好写成需要全部清零的Gate 3 Finding。

## 共享证据继承

逐组件判断，不能一次继承整站。仅当以下条件全部可核对时复用对应owner完整检查：

- 原始报告可访问，绑定有效共享源/依赖身份与owner合同，明确实际测试环境、视口、功能及状态；结论适用且无相关未关闭缺陷。
- 当前组件源/依赖与被测来源一致；若嵌入/转换，存在可核对映射，无法证明一致则不继承。
- 本页没有影响该组件的CSS选择器、脚本、布局上下文或行为覆盖；仅凭组件hash相同不足以判断全局CSS无影响。
- 当前使用的功能、断点和状态在原证据内；更新了owner合同后先比对差异，旧报告不能自动覆盖新要求。

本页仍实际检查当前导航/固定CTA/Logo/法律入口、三端Header—正文—Footer连接与遮挡；两个适用窄屏的菜单打开、选择关闭、背景恢复、焦点返回；Cookie等实际存在组件的入口、打开/关闭及焦点返回。本页特有状态和长内容独立检查，不能继承另一业务页的通过结果。

适用的焦点循环、隐藏背景隔离、跨断点关闭等完整共享检查可引用有效owner证据。证据缺失、版本或合同不匹配、页面覆盖/特殊组装、操作异常时，对受影响组件、状态和视口完整复验；不能证明影响范围时完整复验该组件。问题由owner处理，页面错误消费由页面修正；无关的已验证部分不重新运行。

在现有预检/核验报告逐组件记录：共享源与合同路径/版本/hash；原始报告路径/hash及覆盖范围；本页一致性/无影响覆盖的依据；继承了哪些检查；本页实际检查及证据；缺口和扩大复验原因。继承注明“引用共享验证”，不要标为当前页ACTUAL_RUNTIME或NOT_APPLICABLE；证据类型沿用原始实际类别，并另记来源页面/共享范围。独立审查者直接核对原报告与本页组装，不能只接受执行者的继承声明。

## 图片与参数

三端完整线框必须实际查看，长页逐段覆盖。菜单保留必要状态证据；相同共享状态不机械按三宽另存，只有独特重排、遮挡或无法继承的风险才新增。可用一个证据解释多个要求，但不能用一张静态图声称多端交互全部实测。测量与过程分段留在支持层，独立审查默认不再保存整套相同图片。

交接区分“结构约束”和“当前实现参数”。字号、行高、间距等非明确合同值通常为参数；内容关系、顺序、列数/重排合同及行动所属区域仍为约束。共享owner的明确尺寸/样式要求不可降为自由参数。历史批准中显式锁定的值不自动放宽。

## V0.2 审查不得反向扩大制作

审查者须读取专项标准。每个必修明确违反的要求、位置/视口/状态、实际影响及接受条件；“不够精致/协调/品牌感”不是Gate 3必修。禁止要求风格变体、新视觉资产、无必要的动画、重新设计共享外观或反复调裁切。已有合格样式无需去色或故意降质。

媒体查批准内容、位置/空间、响应关系及可见性；交互查实际适用行为和焦点/键盘，不以最终视觉打磨为通过条件。混合问题只要求修到结构、内容关系、可读性、操作或合同缺陷消除，剩余视觉事项交Gate 4。不因某项改动是CSS就自动放行真实缺陷。

完整规定范围必须核对，身份失配、裁切、对比度、焦点、触控目标及内容遗漏仍是实质问题。结构通过且必修关闭后停止追加视觉意见引起的复审；已有纯视觉建议可以交接，不要求清零。本节不减免Gate 4或Gate 9任何检查。
