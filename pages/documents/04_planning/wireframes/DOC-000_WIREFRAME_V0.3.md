## Finder states

1. Before search — two fields and Find Documents.
2. Public found — verified record metadata + View/Download.
3. Mixed — verified public record plus request-only COA/context item.
4. No public record listed — neutral text + Request Documents.

States 2/3 are internal structural specimens until real records are approved. No dead or disabled action is specified.

## Interaction

- Find validates Grade selection.
- No-record result carries selected Grade/Type into Request Documents.
- Category request links carry Type.
- FAQ uses accessible full-width buttons.
- Long names wrap; focus is visible; mobile targets are at least 44px.
