## 索引与发布边界

正式发布目标按静态单站决定具备Google收录条件：正式canonical、index/follow、sitemap及可抓取的实质页面；生产后由发布责任方跟踪Google实际索引。预览可保持获批准的防索引限制，但需标明环境、适用范围与正式发布前解除条件。旧批次的noindex/无sitemap不是新正式发布标准。

不能以本规则推导404必须返回200或把非内容fallback制造成SEO页面；特殊对象的原合同与“所有正式页面”的适用范围有冲突时，由总控登记具体对象并按原决定权限澄清，不由开发猜测。当前正式域名取页面批准来源，不从旧部署示例推导；预览地址不是canonical来源。
