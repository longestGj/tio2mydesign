# 品牌应用与视觉样例制作

> 项目方法候选 V0.1，2026-09-07。已完成[首轮有限方法验证](../../docs/superpowers/specs/2026-09-07-gate4-skill-validation-v0.1.md)，具体方法仍待用户审阅。由调用任务明确提供获准范围；本文件不授予页面或阶段权限。

将给定方向、品牌和结构制作成可查看的样例与能重复应用的规则。Agent决定本页方向、样例范围及结果取舍；方法负责制作和具体使用检查，不维护页面事实或批准状态。

## 输入与输出范围

接收：

- 视觉方向及要检验的问题；固定和可细化的部分。
- 精确品牌/增补、共享组件与资产来源；样例文字的唯一编辑源、批准布局及操作合同。
- 样例在完整页面的位置、需要的视口与状态、素材用途及可用工具。
- 绝对`output_dir`、`report_path`，允许写入范围及版本约定。

缺少会改变关键视觉决定的输入或路径时指出具体影响，交回Agent补充，继续不依赖它的部分。不要根据品牌截图推定公司能力、根据控件外观猜测动作，或用占位短句替代实际文字。已有输出未获覆盖授权时使用明确的新版本，不替换批准源。

## 1. 将品牌来源落实到用途

按给定权威关系解析当前有效规则，区分直接继承、本次细化和未解决冲突。后续增补可能只修改功能色，不能顺带覆盖Logo自身配色或所有品牌强调色。

对本次实际采用的视觉角色建立简短映射：`用途 → 值/共享规则引用 → 背景与状态 → 样例位置`。包括文字、表面、动作、边界、状态、间距及媒体等适用项，不复制全站品牌手册。

固定值直接继承；可细化项给出数值、可计算关系或带适用条件的响应规则。不同页面上下文可以采用同一规则，不为了独特性创造同义token。来源冲突无法按批准对象、范围和日期解决时，不静默任选。

## 2. 建立真实样例与规则对应

按Agent指定范围选择对应的完整内容片段，保留标题、正文、技术值、单位、帮助、限定条件和关键相邻连接。标明原始位置；截图边界不可隐藏判断所需信息。

同一种样式可用一个代表组件证明，再标明其复用位置。长内容、不同背景、错误/选中状态或窄屏会改变效果时，补充相应样例。独有组件未被覆盖时指出缺口，不把已有卡片样例自动推广成所有组件已经验证。

样例覆盖映射只记录原位置、规则和证据，不复制另一份正文。样例预览内的排列用于比较，不能被误记为批准页面的新模块顺序。

## 3. 制作样式并保持已定结构

复用可靠的规划源与共享资产，制作本地可编辑样例。字体、颜色、边框、阴影、圆角、间距、媒体和状态在同一套规则内应用。若已有批准视觉满足方向，保留并只补本次范围。

在批准布局内处理真实换行和内容驱动高度。不要通过删字、缩短选项、固定裁切、重排模块或移动动作区域使样例更整齐；若确需结构/内容改变，交回Agent并说明具体原因。

| 情况 | 制作时保留的重点 |
|---|---|
| 阅读与技术比较 | 标题/正文层级、对象/单位/限定条件的对应；表格或卡片结构来自输入 |
| 行动与选择 | 主次行动可辨、信息卡与点击目标可辨、选中和获得结果不混淆；状态行为来自合同 |
| 帮助与错误 | 真实长提示与相关字段相邻；不只用颜色表达差异，不自造纠错文案 |
| 媒体与图表 | 按批准用途表达；比例、裁切、重要内容安全区域明确；不添认证、库存、排名或数据关系 |
| 无图片 | 内容及行动自然衔接，无空框或内部占位；不靠臆造实景填空 |

替代文本方向按图片在本页的作用说明；装饰不堆关键词。示意、通用场景与企业实景分清用途，不将素材风格当作真实性证据。新增事实含义交Agent处理。

每个要求的逻辑视口分别调整视觉密度，保留已定响应结构。记录物理尺寸和比例，不能以高像素的手机图当作平板证据。共享组件仅正确消费与连接，不重画Logo或建立本页版本。

## 4. 渲染、查看与核对

确认实际字体与素材载入后导出，并记录渲染器、源版本、逻辑视口、比例和状态。字体或素材不可得时记录候选差异及影响，不能把替代结果说成原样还原。

实际打开全部输出样例，按可读比例查看；长样例分段覆盖，检查真实文字、连接、裁切、异常空白和视觉优先级。源里有文字、图片生成成功或零横向滚动不能替代检查。

功能色按实际文字/背景、边界/相邻面和状态组合核对。可确定纯色组合时计算对比，记录所用值、结果及输入规定的适用阈值。透明层、渐变或照片覆盖时检查实际合成背景与最弱位置，不把纯色token结果直接沿用。无法可靠确认时标明未验证，或在允许范围内改用可验证背景再检查。

按输入的可访问性合同核对字号、焦点可见性和触控区域；静态图只能证明外观及有可靠比例的几何。真实命中区、键盘行为或接收结果不能从状态图推导；实际操作与本地模拟各自记录，不执行真实提交。

检查视觉是否改变含义：强调是否偏离批准优先级，普通信息是否看似操作，文档图示是否被误读为已认证，颜色状态是否像已成功接收。发现问题在允许样式范围内修复；涉及事实、结构或行为的变化交Agent。

记录全部实质问题及位置，区分确定缺陷、可选建议和未验证项。局部样例检查不得输出完整页面合格结论。

## 5. 保存与交回

`output_dir`保存样例源、导出和必要证据；`report_path`保存：

1. 精确输入、样例范围、规则与使用位置、少量关键取舍。
2. 覆盖映射、三端与状态结果、媒体/回退方向。
3. 资产身份：路径、角色、源版本、逻辑/物理尺寸、比例、状态、字节数和SHA-256；依赖/渲染条件可追溯。
4. 实际检查、问题与证据、未覆盖范围及需Agent决定的事项。

规则说明中的数值必须与样例实际使用一致；源改变后更新受影响导出，核对图、源与清单。共享资产可精确引用，不重复复制或登记页面当前Manifest。报告不能抄一套完整B或历轮审查。

从同一路径读回报告，打开资产并核对清单。写入/读取/导出失败时交回已有结果和真实失败，不返回预计路径冒充完成。最后返回 **已保存绝对路径、主要规则与结果摘要、未完成事项**；由Agent读取查看后作取舍、审查交接和阶段判断。
