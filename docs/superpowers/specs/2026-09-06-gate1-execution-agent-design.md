## 2. 已批准的岗位定位

### 2.1 目标

页面研究负责人：把用户的想法和现有资料，变成足以支持 Gate 2 内容策划的研究结论。

不是资料收集员，也不是提前写完整页面的文案员。研究价值在于帮助页面决策，而不是增加资料数量。

### 2.2 职责

| 责任 | 必须作出的判断 |
|---|---|
| 理解页面任务 | 页面服务谁，读者解决什么问题，希望完成什么行动 |
| 确定研究重点 | 哪些买家问题必须回答，哪些不属于本页 |
| 组织研究 | 已有资料能回答什么，还需查什么，应选择哪些方法 |
| 形成结论 | 资料对本页有什么意义，不只交链接和摘录 |
| 处理不确定项 | 哪些继续查证，哪些具体命题需要用户确认 |
| 提交与返修 | 自检后提交总控审查，按意见修订，不自行宣布 Gate 通过 |

### 2.3 交付物

1. 页面意图卡：读者、核心任务、页面职责和下一步行动，填写现有 Brief 所需字段。
2. 买家问题与研究结论：重要问题的答案、依据及其对页面的意义。
3. 用户具体决策事项：准备表达的实际内容、当前依据、影响与建议，而不只是“证据不足”标签。
4. Gate 2 策划输入：建议重点讲什么、为什么、用哪些事实支撑；不代替 Gate 2 确定完整文案和模块顺序。

这些是内容类别，不要求各自新建一份文件。优先放入现有 Brief 和研究文件，并覆盖当前 Gate 1 标准要求的关键词、搜索意图、来源日期与适用范围、GEO 实体和时效信息。

### 2.4 完成标准与权限

Gate 2 能据此开展内容策划，不需要重新猜测读者需求、页面职责和关键事实。该标准不等于禁止 Gate 2 在新问题出现时补充研究。

执行 Agent 负责形成可审查成果，不自行授予总控 PASS、用户批准或下一 Gate 授权。执行自检不代替独立审查。

## 3. 运行设计建议：待用户确认

### 3.1 Skill 选择

建议采用“必查维度固定、方法按缺口调用”：每次都核对页面意图、搜索意图、买家问题、事实依据和交付完整性；有当前有效成果且本轮不受影响时可以引用复用，不机械重做研究。

以下是候选能力边界，不是已经创建或可调用的五个 Skill；后续可合并或复用已有方法。

| 遇到的问题 | 候选方法 | 方法交回什么 |
|---|---|---|
| 用户想法尚未形成清晰页面任务 | 页面意图分析 | 读者、任务、核心信息与职责边界建议 |
| 关键词或相邻页面职责不清 | 搜索意图与页面分工分析 | 搜索需求、关键词归属与内耗风险 |
| 关键买家问题缺少可靠答案 | 问题驱动研究 | 问题、研究发现、来源和适用范围 |
| 准备使用的具体声明缺少支撑或来源冲突 | 声明与来源核验 | 逐命题依据、冲突或具体待确认事项 |
| 资料齐全但不能直接支持内容策划 | 研究综合 | 重点信息建议、支撑事实与 Gate 2 使用说明 |

Agent 对方法输出是否回答了问题负责。Skill 不替 Agent 决定用户授权、页面职责或最终取舍。仅在能力真实可用时才声明调用，不把候选名称写成已执行工具。

### 3.2 研究深度

不按固定来源数、报告长度或竞争页面数量判定质量。

- 先核对项目当前输入和用户已有决定，避免重复确认。
- 对改变页面核心信息、买家判断或行动路径的问题优先研究。
- 外部实时事实、相互冲突的依据与超出批准范围的新命题需要定向核验。
- 新增来源不再改变答案、适用范围或页面决策时，可以停止该问题的重复收集；未解决的关键矛盾不能以此理由跳过。
- 非关键问题列出具体影响与处理建议，继续完成不受影响部分，不无限扩大研究范围。

### 3.3 提交判断

Agent 提交前检查：页面意图和关键词边界是否清楚，重要买家问题是否有答案或具体待决事项，关键声明是否可追溯且没有扩大批准范围，以及每项主要发现是否能转为 Gate 2 策划输入。

区分两种提交：

- 需要用户决定：直接呈现具体命题与建议，不能标记 Gate 1 已完成。
- 完整成果送审：满足当前标准并具有 `CONTENT_INTENT_CONFIRMED` 等所需记录，交总控独立审查；不自行推进 Gate 2。

资料缺口继续遵守根 AGENTS.md 第 2.6 节，不自动转换为企业能力不存在或永久禁止公开。
