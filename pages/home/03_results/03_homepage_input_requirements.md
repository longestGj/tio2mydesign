# 首页与信任型副页输入资料清单

## 使用方法

该清单用于把企业真实材料整理成可审核输入。每项应标记：`已有 / 待补 / 待核 / 不公开 / 已批准`。没有材料支撑的能力不进入正式首页文案。

## 1. 企业主体与品牌关系

- `TiO₂ Malaysia` 前台品牌的正式写法、Logo 使用规则和域名归属；
- IKHLAS TITANIUM (MALAYSIA) SDN. BHD. 的注册名称、编号、注册地址、运营地址；
- TiO₂ Malaysia 与 IKHLAS 的一句话法律/运营关系；
- 制造地点、运营主体、工厂主体之间的准确关系和可公开措辞；
- 电话、域名邮箱、营业时间、联系人/岗位；
- `mytio2.com` 与 `tio2malaysia.com` 的对外关系说明。

## 2. 产品与技术资料

- 现行牌号总表、版本日期、状态；
- 每个牌号的 rutile/process、主要应用、关键指标和限制；
- Chloride grades：M-350、M-510、M-896、M-895、M-200、M-210、M-340、M-886；
- Sulfate grades：M-996、M-2196、M-108、M-52；
- M-2377 的工艺和正式定位待技术资料确认；
- CR-901 的高纯 rutile / vapor-phase oxidation 描述及证据；
- 是否有停产、区域限制、最小订量或不可公开信息；
- 应用映射：coatings、plastics、masterbatch、printing inks、paper、specialty；
- 竞品替代/对标信息是否允许公开，以及审核责任人。

## 3. 原产地与可追溯材料

- COO 样本、签发主体、适用交易/批次、可公开范围；
- 原料、生产、包装、装运各阶段的 origin/traceability 说明；
- 工厂地址和现场实拍；
- 产品标签、包装、批号和装柜照片；
- 可用于买家尽调的来源、编号或查询方式；
- 任何“Malaysia-origin / Malaysia-made / manufactured in Malaysia”表述的批准版本。

## 4. 文件与合规

- TDS、SDS、COA、COO、REACH-related documents 的目录；
- 文件版本、日期、语言、适用牌号、适用市场；
- 哪些只展示名称/说明，哪些可在批准后发送；
- 发送前需要的买家资格或保密条件；
- 认证/注册的机构、编号、范围、有效期、查询渠道；
- EU Only Representative 等关系的合同/授权和批准用语；
- EU、UK、India、Brazil 各市场的已确认要求与待法律/合规审核项；
- 文件申请的内部责任人、审批和发送记录方式。

## 5. 质量与技术支持

- QC 流程图、进料/过程/成品检验节点；
- 实验室、设备、人员和检验实拍；
- 批次 COA 样例及可遮盖字段；
- 质量体系证书和有效性资料；
- 不合格、投诉、追溯和纠正流程的可公开摘要；
- 技术支持人员/岗位、可回答的问题、联系方式和响应流程；
- 牌号推荐的技术审核规则。

## 6. 供应、包装、仓储与出口

- 可公开的生产/供应机制、产能或供货稳定性说明；
- 包装规格、托盘、标签和定制条件；
- 仓库实拍、地点和运营关系；
- 装柜、港口、单证和出口协调流程；
- Port Klang 等地点表述的准确关系；
- MOQ、样品、典型交付条件、Incoterms（如允许公开）；
- 不同目标市场的包装/文件差异；
- 供应中断、替代牌号或备选流程能否公开。

## 7. RFQ / Sample / Documents 流程

- RFQ 接收邮箱或 CRM、负责人、备份责任人；
- 首次响应的真实 SLA；
- 表单必填字段和隐私同意；
- 销售线索来源标记（区分两站与市场）；
- 技术推荐、报价、样品、文件申请的内部流转；
- 垃圾询盘和企业邮箱验证策略；
- 样品资格、数量、运费和交付限制；
- 文件发送审批与记录。

## 8. 图片与页面资产

- Logo 的正式 SVG、横版/竖版/单色版本和 favicon；
- 企业自有工厂、人员、QC、包装、仓库、装柜、港口相关图片；
- 每张资产的拥有者、拍摄日期、地点、人物授权、可公开范围；
- 图片内容说明、建议 ALT、文件名和版权状态；
- 原图清晰度和用于 Web 的压缩版本；
- 禁止使用或需替换的库存图、AI 图和未经授权 Logo。

> 视觉标准未规定固定像素/体积数值。具体响应式尺寸、格式、压缩目标和性能预算应在设计/实施规格中批准，并通过实际页面验证。

## 9. 客户与市场输入

- 终端制造企业的细分行业和典型岗位；
- EU、UK、India、Brazil 各市场的采购流程差异；
- 高频询盘问题、拒绝原因、采购量级、验证周期；
- 买家对 origin、compliance、supply stability 的原话或销售记录；
- 可公开案例、匿名案例或客户证言及授权；
- 不同市场的语言、货币、单位和联系偏好。

## 10. 审批记录

每条进入正式页面的事实建议保留：

- 事实 ID；
- 页面表述；
- 支撑材料；
- 适用页面/牌号/市场；
- 业务审核人；
- 技术/合规审核人；
- 批准日期和到期复核日期；
- 两站同步状态。

## 设计阶段的进入条件

- 关键词研究完成人工批准；
- 上述关键资料至少可支持原产地、主体、产品、文件、供应、RFQ 六类判断；
- 未核事实被明确排除或标记；
- 双站角色、共享事实源和表单归属得到批准；
- 之后才根据 2–3 个策略方向分段确认首页设计。
