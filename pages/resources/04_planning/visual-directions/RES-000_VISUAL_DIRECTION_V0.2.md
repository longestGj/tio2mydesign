## 1. Direction

Keep the established Navy/Teal industrial editorial system. The visual change is hierarchy, not a new style: genuine research content gains the highest weight after the Hero, decision paths become concrete and evidence becomes compact.

### Visual hierarchy

1. Deep Navy Hero with direct TiO2 procurement promise.
2. Featured Resource as the strongest light-surface editorial card.
3. Three equal decision paths as the organizing layer.
4. Compact evidence principles.
5. Buyer Questions as extractable knowledge.

The deleted owner-card grid is not replaced.

## 3. Section Treatment

### Hero

- Preserve the Deep Navy block and generous left-aligned copy.
- Remove the disclaimer rule so the CTA is closer to the value statement.
- Desktop diagram uses one START circle and three aligned outline nodes: Sourcing, Technical Evaluation, Trade & Market.
- Diagram is visually subordinate and completely hidden on mobile.

### Featured Resource

- One large card is intentional and honest; it must not be visually padded to resemble three items.
- Use an editorial left rule, content-type label, title, two-to-three-line description and a descriptive action.
- No stock image, flag, date badge, fake author or status pill.
- The unused grid width carries a short non-interactive definition of the Hub's three content families, not a second resource.

### Decision Paths

- Three equal cards retain the existing linear icon language.
- Titles and bodies contain concrete titanium dioxide procurement entities.
- Cards are informational, not disguised navigation buttons.

### Latest Research

- Hidden in the current proof because only one real resource candidate exists.
- Future two-plus state uses a compact list, not another identical card grid.

### Evidence

- Soft Background, three compact columns with a small number marker/rule.
- No fourth item and no extended disclaimer prose.

### Buyer Questions

- Preserve the two-column Desktop / one-column Mobile accordion language.
- First answer expanded in the proof to demonstrate readable answer typography.

## 4. Global Chrome

- Production primary SVG Logo on Header and reverse SVG Logo on Footer.
- Desktop Resources current state: Bold + 3px Teal underline; no visible `CURRENT` label in the new candidate proof.
- Mobile Menu current state: Bold + 4px Teal left marker; no visible label.
- Fixed RFQ in Desktop Header, Mobile Header, Mobile Menu and Footer.
- Footer keeps global navigation only; no page-local `Research paths` or `Buyer questions` links.

The current-label removal follows formal Global Chrome V0.5 (`GHC-CURRENT-TEXT-REMOVAL-PCR-01 = PROJECT_CONTROL_REVIEW_PASS / CLOSED`); the RES body revision consumes but does not alter that shared contract.

## 5. Mobile-specific Direction

- Hero diagram hidden at 390px.
- Hero CTA full width and minimum 48px.
- One-column Resource and path cards with 24px padding.
- Evidence principles stack with visible separation but no oversized gaps.
- FAQ answers remain 16px; long questions wrap naturally.
- No horizontal rails, clipped arrows or card-edge truncation.

## 6. Claim-safe Visual Boundary

- No factory, Malaysia flag, port, customs, certificate, document preview or product pack is used.
- No diagram encodes a grade relationship or market outcome.
- RES-ORIGIN card represents an actual project page candidate but carries no date/status metadata.
- No current Trade item is shown.
- PRODUCT V0.3 remains a non-visible evidence boundary; no grade rows render.
