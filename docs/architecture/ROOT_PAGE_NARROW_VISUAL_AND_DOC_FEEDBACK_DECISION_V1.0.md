# 一级页面窄屏视觉与 Documents 反馈稳定性决定 V1.0

日期：2026-09-21。决定 ID：`ROOT-NARROW-VISUAL-20260921`。状态：`USER_APPROVED / ACTIVE / DESIGN_CONTRACT_ONLY`。

## 1. 批准来源与范围

四个一级页面 `MARKET-000`、`DOC-000`、`RES-000`、`ABOUT-001` 在当前 D32 页面组合的 Gate 4／Gate 5 中暴露出同一组窄屏视觉合同冲突。总控向用户集中提交三项决定：受控 H1 自然换行例外、`<=340px` 的共享单行 Eyebrow 规则，以及 Documents 选择器稳定反馈区。用户于 2026-09-21 回复“同意”。

本决定补充 [Root Page Hero V1.0](ROOT_PAGE_HERO_SHARED_COMPONENT_SPEC_V1.0.md)，只作用于上述四页的当前 D32 设计组合及其后续实现交付。它不回写历史 D16 候选或已完成验收记录，不改变页面正文、SEO/GEO、Schema、CTA 目标、页面职责、Global Chrome 或发布状态。

## 2. H1 受控自然换行

共享 `36px / 700` 移动标题层级、Hero 外边距、内边距、标题全文及信息顺序保持不变。下列自然行数获准作为页面与断点限定例外：

| 页面 | 1024px | 320px | 决定 |
|---|---:|---:|---|
| `MARKET-000` | 2 | 3 | 继续满足共享默认值，不新增例外 |
| `DOC-000` | 3 | 4 | 仅 320px 允许自然四行 |
| `RES-000` | 4 | 5 | 1024px 允许四行；320px 允许五行 |
| `ABOUT-001` | 4 | 7 | 1024px 允许四行；320px 允许七行 |

这些例外不授权缩写、删改或人为拉长标题，也不扩张到其他页面或断点。既有 390px 页面定向例外继续按原批准范围有效。

## 3. `<=340px` 共享 Eyebrow 规则

四页在 `<=340px` 使用同一窄屏呈现规则，目标是保持 Eyebrow 单行。它继续保留批准的大写语义、品牌字距和颜色，不允许页面私有修补或改变可见文字。具体生产实现由开发方在 Gate 8 选择；D23只交付可验证的视觉结果和约束。

该规则关闭 `MARKET-D32-G5-R01` 与 Resources 对应等待项的设计授权缺口，但两页仍须由作者更新设计组合，并由指定的不同身份 Gate 5 审查者完成定向复验后，Finding 才能关闭。

## 4. Documents 稳定反馈区

`DOC-000` 在 `<=340px` 为选择器错误反馈预留两行空间，使 Continue 控件在初始、空选报错、有效选择与清空四种状态保持稳定位置。现有错误文案、字号、焦点、操作顺序、选择语义和目标均不改变。

本节定义结果合同，不规定 CSS 或生产代码写法。`DOC-D32-G5-R02` 仍须经过作者定向修订和原指定独立审查者复验后关闭。

## 5. 执行与授权边界

- 页面作者只更新 D23 设计候选、证据、冻结与交接身份；不得进入或修改任何开发仓库。当前生产承接仓库按最新用户决定为 `D:\32NextJS`。
- Gate 5审查者只读核对本决定及未变回归，不替作者修订，也不自行关闭 Gate。
- 总控接收审查结果，并在必修项关闭后按常设授权关闭 Gate 4／5组合；不重复专业审查。
- Gate 6、Gate 8、Gate 9按各自合同和授权继续。生产实现只交现有“02开发”任务；本决定本身不启动开发、部署、发布、DNS或索引。

## 6. 回退与风险

主要风险是把页面限定例外扩张为全站新默认，或把结果合同误写为 D23 生产实现要求。任何扩张均需新的有效决定。若回退，只回退本决定对当前四页的增量授权，保留原共享合同、历史证据与页面已批准内容。
