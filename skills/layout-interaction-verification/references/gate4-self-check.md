# Gate 4自检：同一完整覆盖，按变化补验 V0.2

2026-09-21合并设计覆盖：从Gate 2批准全文/行为及4A记录核对页面家族、参照批准身份、共享组件、本页必要差异、内容/操作关系；新页不强索Gate 3冻结。完整核验不能只看外观。旧有效Gate 3成果可继承，局部结构证据不替代最终三端整页。

仅用于Gate 4执行方的SELF_CHECK；不减免独立审查，不自动用于Gate 3或Gate 9。Agent、制作Skill和核验Skill共同完成一次可追溯的完整自检，不因方法切换、报告交回或冻结而自动追加一轮相同检查。

## 范围与记录

调用方传入共同工作集、准确源/依赖/渲染条件、已有覆盖记录及本次范围：`INITIAL`完整自检、`CAPTURE_CHECK`正式捕获核对、`TARGETED`变化补验。在既有报告或运行记录中记录检查对象、视口/状态、证据、实际执行者、源身份、结果和缺口；不要求新建平行报告。可合并等价实例的记录，但必须覆盖全部批准内容、三端视觉及适用状态/本地行为。

已有观察只有在对象、来源及影响范围未变、能追溯实际检查且证明同一要求时才可继承。仅有另一方法的PASS摘要不够。4A样例可支持相应局部判断，不能替代4B完整页面和模块连接检查。身份不明、必需未测或存在缺陷时不得声明完整通过；“一次”不是限制必要返修轮数。

## 制作与预检

制作方边制作边发现问题，稳定后由核验方法补齐共同覆盖中的缺口。已完成且有效的内容、几何、颜色与操作检查直接引用，制作Skill不再重复跑相同清单。Agent检查覆盖、冲突和就绪条件，对具体疑点补验，不把接收方法结果变成另一轮全页自检。

三端阅读采用原图缩放、既有分段或浏览器滚动，保留连接上下文。诊断默认不每轮持久保存完整三端、全部分段或所有状态截图；新诊断图须对应可读性缺口、具体Finding、采集异常或明确合同要求，并记录证明对象。需要全页证据时保存全页，不用数量上限漏查。既有失败及历史证据保留，不借本规则删除。

## 正式捕获核对

预检完整且必修关闭后，锁定源、依赖、字体/媒体与渲染条件，导出合同要求的正式三端及必要状态；预检图不直接冒充冻结后正式图。捕获后补齐资产身份，形成完整冻结包。

实际打开全部正式全页和关键状态，按可读比例确认：字体/素材加载、视口和DPR依据、捕获范围、状态/焦点、完整到Footer、无采集造成的裁切或空白，并与已自检源和条件对应。机器批量核对路径、物理尺寸、bytes、SHA及索引。不能只看缩略图或工具PASS。

源、依赖、条件与表现一致时，CAPTURE_CHECK不重新跑完整文案双向比对、全部交互或全部几何测量。出现差异先确定来源，再检查受影响对象；不能以“捕获检查”忽略实际视觉缺陷。必要捕获动作不等于重跑全部行为测试。正式证据最低要求保持。

## 变化补验与停止

| 变化 | 补验范围 |
|---|---|
| 页面/样式/关键依赖改变 | 原问题、受影响内容/状态及相邻回归；布局或字体等全局变化核对三端，必要时全量重检 |
| 采集条件或截图错误 | 重捕受影响证据并做捕获核对；若表现影响先前结论，补相应视觉检查 |
| 仅索引/报告字段错误，原件与来源可信 | 批量核实相关身份与字段、索引引用；不重跑未变页面或重拍图片 |
| 无实际变化、无缺口或疑点 | 引用有效结果，不新增同范围自检与资产 |

变更后更新受影响身份及记录；未变有效资产精确引用。所有必需覆盖成立、正式捕获正确、必修关闭且身份一致时，交回就绪结果停止自检，进入获授权的独立审查。可选润色不启动新一轮制作。
