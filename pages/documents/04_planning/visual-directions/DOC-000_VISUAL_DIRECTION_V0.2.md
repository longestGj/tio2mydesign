## 1. Inherited system

- Navy + Teal palette, white and soft-gray editorial sections.
- Existing typography, spacing, document-index motif and card/ledger language.
- Production SVG Logo and Global Chrome V0.5.
- Desktop 84px Header, Mobile 64px Header and Deep Navy Footer.
- Fixed navigation order and permanent global Request a Quote.

No Header, Mobile Menu, Footer, Logo or first-level navigation change is proposed.

## 2. Visual hierarchy

1. Hero primary Request Documents is the strongest page-body action.
2. Category request links are teal text actions, subordinate to the Hero/primary conversion.
3. Scope uses a soft-gray three-column band.
4. Request steps use Deep Navy to signal controlled review without warning language.
5. The conversion bridge repeats Deep Navy and one primary button after the checklist.
6. FAQ is calm and editorial; the final request link is deliberately light.
7. Global RFQ stays in Header/Footer and does not enter body modules.

## 3. Image and icon rule

Use the abstract six-line document index and small consistent line icons only. Do not use fake PDF previews, certificate images, government seals, factory/stock photography, flags or decorative molecules. The page must remain complete with no photography.

## 4. Desktop and 390px direction

- Desktop: two-column Hero and 3+3 taxonomy ledger; 1200–1320px content container.
- 390px: true single-column taxonomy and scope; no compressed two-column cards.
- Primary CTA is near-full/full-width on mobile.
- Long text wraps; no horizontal overflow; no artificial hero minimum height.
- Focus outline remains visible; hover never carries essential meaning.

## 5. State direction

| State | Visual rule |
|---|---|
| No public records | Complete guidance/request page; no empty shelf or zero message |
| Eligible public record | Quiet factual record with Product/Grade, Type, Revision/Date, English and Scope |
| Controlled record | Request action, no download icon or approval colour |
| Route unready | Release blocker outside Buyer Clean; no disabled/hidden slot or Contact fallback |
| Long name | Natural multi-line wrap |
| No image | Text/line system remains complete |
