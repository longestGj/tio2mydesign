## 保留的质量条件

- 完整批准内容、三端视觉、适用状态/本地操作必须覆盖。
- 正式全页及关键状态必须实际查看，确认捕获正确；预检图片不能直接冒充冻结后正式图。
- 页面或全局依赖变化按影响复验，必要时完整重检；不是强制只能检查一次。
- 诊断截图按缺口、Finding、采集异常或合同要求新增；保存既有历史，不删除资料。
- 一次独立审查保持，执行方自检不替代新Gate 5/现行Gate 4最终独立审查。
