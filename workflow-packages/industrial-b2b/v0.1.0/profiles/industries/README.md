# 工业品行业适配

行业适配只提供问题和关系模型，不提供企业事实、产品适用结论或页面批准。W1先确认实际供给，再选模型；允许混合，不强套型号、TDS或市场页。

| 供给类型 | W1事实与W2采购问题 | W4组织候选与特殊风险 |
|---|---|---|
| 材料/配方产品 | 成分范围、性能条件、载体/基材、测试方法、批次差异、应用限制 | 型号—基材—工艺—用途关系均需来源；共同用途不代表可互换 |
| 设备/部件 | 型号/配置、尺寸、工况、接口、选型边界、维护与交付 | 产品—工况—配置—兼容关系；典型参数不能变保证值 |
| 加工/工业服务 | 输入材料、工艺能力、公差/验收、批量与交付条件 | 服务—材料—工艺—案例；案例不推导所有订单能力 |

竞争分析对照客户真实替代选择、选型障碍、证明与联系路径，不按竞品数量或流量评分替企业决定战略。认证、法规、技术等效和地区服务承诺均按具体证据核验。

首版只定义这些候选模型。色母粒可从材料/配方模型开始验证，但尚未读取新站全部事实或执行真实试跑，不标记该行业已验证。
