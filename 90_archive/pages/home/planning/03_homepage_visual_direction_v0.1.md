## 3. 两套方向共同底线

### 3.1 品牌与视觉系统

- 定位：Malaysia Origin + Industrial + International B2B + Technical + Trustworthy。
- 使用视觉标准的 `#062B5B` Primary Navy、`#031B3A` Deep Navy、`#00A99D` Malaysia Teal、`#14B8A6` Accent Teal、白色、`#F5F8FB` Soft Background、`#D9E2EC` Border Gray、`#334155` Body Text。
- 字体方向为 Inter → Arial → Web-safe sans-serif。
- Primary CTA 为 Teal + White；Secondary CTA 为透明/白底 + Navy 边框；按钮保持 6–8px 工业 B2B 圆角，不使用胶囊按钮。
- 不使用旅游式 Malaysia、廉价化工模板、电商组件、SaaS 仪表盘、霓虹炫光、玻璃拟态或大面积渐变。

### 3.2 Header

PC 可见顺序严格保持：

```text
Home | Markets | Products | Applications | Documents | Resources | About | Request a Quote
```

- Home 为第一个可见文字入口，Logo 不替代 Home。
- 不出现独立 Malaysia Origin 导航。
- 移动端显示 Logo、Menu、紧凑 RFQ。
- 本阶段不绘制完整展开菜单；后续必须沿用：Home、Markets、Products、Applications、Documents、Resources、About、Request a Quote。

### 3.3 Hero 与 CTA

- Hero 工作主题明确包含 `malaysia titanium dioxide`。
- 主 CTA：Request a Quote。
- 次 CTA：View Products。
- Hero 不出现 Request Documents 或 Sample。
- `Malaysia-Origin Supply Platform` 只作为已批准战略定位的工作表达；任何制造地点、Made in Malaysia、COO、批次追溯、稳定供应、交期或文件可用性仍受证据门槛控制。

### 3.4 紧凑采购入口

两套首屏底部均只显示一个紧凑的三入口条：

1. Markets

3. Documents

它是 Hero 后的采购决策导航，不是第二个 Hero，也没有重复正文。

## 4. Direction A — Industrial Editorial

### 4.1 核心概念

Direction A 把 TiO₂ Malaysia 处理成高级工业材料品牌：白色与 Soft Background 为主，大留白、超大标题、克制的 Teal 强调，以及一个独立的品牌符号编辑构图。它的气质接近专业工业材料年报或高端材料品牌，而不是化工供应商模板。

### 4.2 信息与构图

- Header 使用白底、170–210px 横版 Logo 和完整导航。
- Hero 左侧以强 H1、短说明和双 CTA 建立主线。
- Hero 右侧不放工厂或物流图；只使用已批准 Icon，在 Deep Navy 编辑画框中作为装饰氛围。
- Malaysia 识别来自 Logo、Malaysia Teal 和克制的定位标签，不依赖国旗或地标。
- 三入口采购条采用白底、清晰编号和宽松列间距，让 Markets / Products / Documents 自然承接后续页面。

### 4.3 买家适配

- 对采购型买家：主 CTA 和三个采购入口非常直接；视觉噪音低。
- 对技术型买家：首屏技术数据较少，但 Products 与 Documents 路径清晰，后续模块可补充技术深度。
- 风险：如果完整首页后续缺少结构化 Products/Documents 模块，可能显得品牌表达强于技术说明。因此扩展时必须在 Markets 后快速进入 14 grades 与文档路径。

### 4.4 移动表现

- Logo/Menu/RFQ 保持紧凑。
- 标题优先，装饰 Icon 退到低透明度背景，不占用独立大图片区。
- 双 CTA 与三入口仍在 844px 首屏内完整可见。
- 移动端视觉更轻，后续完整页面更容易控制长度。

## 5. Direction B — Technical Procurement System

### 5.1 核心概念

Direction B 把首页首屏处理成工业采购入口：Deep Navy 技术网格作为背景，右侧是一张纸质技术规格页式的 Procurement Scope。它强化结构、文件与数据语言，但有意避免仪表盘、KPI 卡、筛选器或 SaaS 控件。

### 5.2 信息与构图

- Header 仍为白底完整导航，避免整个页面过暗。
- Hero 左侧是工作标题、事实门槛和双 CTA。
- Hero 右侧只展示已批准的结构性信息：四个市场路径、14 grades、Documents Hub + Request Documents 两条路径。
- 右侧不是能力证明，也不宣称证书或文件可用；明确显示 `NO CERTIFICATION / AVAILABILITY CLAIM` 和 `FACT CLAIMS PENDING`。
- 三入口采购条延续深蓝技术系统，使 Markets / Products / Documents 的后续衔接更强。

### 5.3 买家适配

- 对采购型买家：市场、产品和文件路径一眼可见，采购逻辑最强。
- 对技术型买家：结构化信息密度更高，更接近规格页和文档系统语言。
- 风险：如果后续完整首页持续复制白色数据板和编号行，容易向 SaaS 仪表盘或企业门户偏移。完整首页扩展必须在 Markets/Products 中引入真实工业内容和足够留白。

### 5.4 移动表现

- Hero 内将规格页压缩为三行采购范围，信息仍完整。
- CTA、技术板和三入口均在 844px 内可见，但信息密度明显高于 A。
- 后续扩展时必须避免继续纵向堆叠数据板，否则移动页会显得拥挤和过长。

## 6. A/B 逐项比较

| 比较项 | Direction A — Industrial Editorial | Direction B — Technical Procurement System |
|---|---|---|
| 第一印象 | 高级、克制、材料品牌感强 | 严谨、结构化、采购系统感强 |
| 采购型买家适配 | CTA 与入口清晰，阅读压力低 | 市场/产品/文件范围更快被理解 |
| 技术型买家适配 | 依赖后续 Products/Documents 补充技术深度 | 首屏已经建立技术与文件语言 |
| Malaysia 识别方式 | Logo + Teal + 战略定位标签；无地标/国旗 | Logo + Teal + Malaysia titanium dioxide 主题；无地标/国旗 |
| 图片策略 | Approved Icon 作为大幅编辑构图和氛围 | Approved Icon 作为技术规格页的小型品牌识别 |
| Header/Hero 信息密度 | 低至中；留白明显 | 中至高；信息更结构化 |
| CTA 突出程度 | 非常突出，几乎无竞争元素 | 突出，但与右侧采购范围板共同分配注意力 |
| 与 Markets/Products 衔接 | 通过轻量三入口自然下沉 | 通过范围板 + 三入口形成更强逻辑衔接 |
| 移动端表现 | 更轻、更舒展，更容易控制完整页长度 | 更紧凑、更专业，但继续扩展时易拥挤 |
| 误导事实风险 | 较低；只有品牌氛围图 | 较低至中；结构数字虽已批准，仍需避免被误读为能力数据 |
| 扩展完整首页难度 | 中等；需确保后续技术模块足够强 | 较高；需持续抑制 SaaS/仪表盘倾向 |

## 7. 推荐

推荐 **Direction A — Industrial Editorial** 作为完整首页视觉系统的基础，并在后续 Documents、Products 或 Resources 模块中选择性借用 Direction B 的技术规格线、编号和数据/文件语言。

理由：

1. 它更符合用户此前希望“不要太死板、不要过度复杂”的反馈，同时仍保持 Premium International Industrial B2B 气质。
2. 在没有可用企业实拍和证明资产的现阶段，A 能以已批准品牌 Icon 和留白建立质量感，事实误导风险最低。
3. 它更容易控制移动端长度，也更不容易变成 SaaS 页面。
4. Markets / Products / Documents 三入口已经提供足够采购导向，后续可在相应模块增加 B 的技术秩序，不需要让 Hero 承担全部信息。

此推荐不等于自动选择。主控和用户必须明确选择 A、B，或批准“以 A 为主、借用 B 的技术语言”后，才能扩展完整首页视觉稿。

## 8. 如何避免此前被否决版本的问题

- Header 不使用旧 `Malaysia Origin` 独立导航；Home 明确可见且第一。
- Hero 不把 Origin 或 Documents 放在 Markets/Products 之前；采购主入口明确是 Markets / Products / Documents。
- 不使用假工厂、港口、实验室、仓库、装运或概念图作为企业证明。
- 本轮只设计首屏与紧凑采购条，不提前完成长页，也不复制重复模块。
- 移动端显示 Logo、Menu、RFQ；完整菜单顺序在本文档中锁定，不允许后续隐藏导航。
- Hero 所有营销表达均为工作文案，并标 `COPY DRAFT / FACT COPY PENDING`。
- 不宣称稳定供应、产能、交期、认证、文件可用、制造地点或批次追溯。
- Documents 只作为采购入口名称，不在首屏展示 REACH/TDS/SDS/COA/COO 正式卡片。
