## 1. Project-control Conclusion

The package passes project-control review for user decision. Its central thesis is technically defensible and operationally useful:

> The production route can influence how the base pigment is formed, but the route label alone is insufficient to establish a grade-level performance conclusion.

The package avoids the main failure mode found in current comparison content: turning chloride/sulfate labels into universal rankings for quality, opacity, undertone, durability, application or environmental performance.

## 2. Concrete Direction Submitted to the User

- **Audience:** industrial procurement/sourcing teams supported by formulation, technical, quality and regulatory reviewers.
- **Buyer outcome:** understand the labels, reject unsupported route-wide conclusions, and build a grade-level evidence/test plan.
- **H1:** `Chloride vs Sulfate Titanium Dioxide: A Buyer’s Evaluation Guide`.
- **Hero promise:** `Understand what the production route tells you—and which grade-level evidence still needs to be checked before qualification.`
- **Direct answer:** the two labels identify different production routes; route can be technically relevant, but the label alone is insufficient to establish grade-level opacity, hiding power, undertone, weatherability, dispersion or formulation-suitability conclusions.
- **Page-specific content:** route snapshot; can/cannot-tell distinction; overlap evidence; grade-level evaluation framework; qualification workflow; sources/review accountability; conditional owner-page exits.
- **CTA:** Products first; chloride/sulfate process-page links only when both relevant routes are approved and live.
- **Evidence boundary:** official sources for process facts; first-party grade examples only for application overlap; no vendor advocacy promoted to neutral fact.
- **Schema:** Article remains conditional on real visible author/publisher/date/review data; FAQ Schema is not assumed.
